# テストの境界

`tools/extractor.Tests/` は抽出機の外部から観測できる結果を検証する。

- 抽出規則を変えるテストは、入力 plugin と期待する record、field、文字列、SQLite 行の関係を示す。
- SQLite writer のテストは一時 database を使い、保存値と再実行時の重複防止を検証する。
- 条件、感情、話者などの補助事実は、翻訳文の推測ではなく抽出元の record として検証する。
- 実データを必要とするテストには理由を明記し、通常の単体テストから分離する。
- 実装内部の private helper ではなく、公開された抽出結果か SQLite 出力を検証する。
