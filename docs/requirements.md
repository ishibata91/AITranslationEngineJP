# 業務要件

このプロジェクトが満たすべき業務上のゴールを定義する。
「どう実現するか」のシステム要件は別文書で扱い、ここには書かない。

## 目的

Skyrim Mod の英語テキストを、文脈に合った自然で高品質な日本語へ翻訳したい。
手作業翻訳の負担、訳語のぶれ、キャラクターの口調崩れを減らすことが狙いである。

## 業務要件

### 1. Skyrim Mod を翻訳したい

- Skyrim Mod のテキストを日本語へ翻訳できること。
- 目的: 英語のままでは日本語環境でのプレイ体験を損なう。

### 2. 単語の一貫性を保ちたい

- 同じ固有名詞・用語は、Mod 全体および複数 Mod 間で同じ訳語に揃えたい。
- 目的: 同一語が箇所ごとに違う訳になると、プレイヤーが混乱し品質が落ちる。

### 3. NPC の口調を保ちたい

- NPC ごとの話し方・性格を反映した訳文にしたい。
- 目的: 全 NPC が画一的な口調だと、キャラクターの個性と世界観が失われる。

### 4. xTranslator 形式で出力したい

- 翻訳結果を xTranslator 互換形式で出力したい。
- 目的: xTranslator は Skyrim 翻訳の標準ツールであり、既存の翻訳ワークフローにそのまま乗せられる。
