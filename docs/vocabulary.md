# 用語

`spec.md` と `design.md` は、要求の文に現れる語か、この file にある語だけを使う。新しい名詞が要る場合は、ここへ足すことを人間へ諮る。足さない場合は名詞を作らず、動作を説明する文で書く。

1 語につき、日本語での意味、対応する器または場所、その語で呼ばない対象を書く。同じ対象を指す呼び名が複数ある場合は、この file にある呼び名を使う。

## 翻訳の材料

| 語 | 意味 | 器または場所 | その語で呼ばない対象 |
| --- | --- | --- | --- |
| 既訳 | 人間が作った訳。作者が Bethesda か mod の訳者かは問わない | `reference_translation`、`master_term` | 実行内で AI が付けた訳 |
| 英日対 | 同じ record の同じ field について、英語の文言と日本語の文言の両方を解決できた組 | `reference_translation` の 1 行 | 英語だけ取れた文言 |
| 翻訳対象の原文 | 利用者が選んだ plugin の、これから訳す文 | `extracted_field` | 訳を集めるために読んだ他の plugin の文 |
| 用法の集計 | 台詞の英語原文から数えた、各英単語が小文字で出た回数と、文頭以外で大文字始まりで出た回数 | `internal/core/termusage` | 訳語の候補そのもの |

## 訳語の器

| 語 | 意味 | 器または場所 | その語で呼ばない対象 |
| --- | --- | --- | --- |
| 横断辞書 | 既訳から作る、どの plugin を訳す時も使う訳語。永続する | `master_term` | 実行内で AI が付けた訳 |
| plugin 内訳語 | 対象 plugin について実行内で AI が付けた固有名の訳。その実行と その plugin に閉じる | `proper_noun` | 横断辞書へ入る訳語 |
| 機械置換辞書 | 本文中の固有名を訳語へ置き換えるために、横断辞書と plugin 内訳語を合流して組む表 | `internal/core/dictionary` | 保存される table |

`master_term` を指す呼び名として、コード中に `確定訳語`・`権威訳`・`既訳辞書` が残っている。触る task で `横断辞書` へ揃える。

## 作業成果物

| 語 | 意味 | 器または場所 | その語で呼ばない対象 |
| --- | --- | --- | --- |
| 事象 | 人間が見た画面、操作、ログ、失敗、期待との差分 | `plan.md` の事象欄 | 何をしたいか |
| 要求 | 事象から起こした、何をどうするか | `plan.md` の要求欄 | 事象の言い換え |
| 仕様 | 変更後に成立させる振る舞い。要求番号から続く番号を持つ | `spec.md` の各要求の節 | 実装が守る内部の性質 |
| 前提条件 | その仕様が問われる状況 | `spec.md` の仕様ごとの第 2 段 | 仕様そのもの |
| 確かめ方 | その仕様の成立を、人間が触れる物のどこで見るか | `spec.md` の仕様ごとの第 2 段 | テストの実装手順 |

`spec.md` の項目は `仕様` と呼ぶ。`期待値` はテストが照合する値を指すので、`spec.md` の項目名には使わない。
