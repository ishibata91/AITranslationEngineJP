# 画面設計: 未完了ジョブ一覧

- 目的: 未完了の翻訳ジョブを確認し、必要なジョブを再開する。

## ワイヤーフレーム

```text
+------------------------------------------------+
| [1]                                            |
| +--------------------------------------------+ |
| | [2]                                        | |
| | +----------------------------------------+ | |
| | | [3]                                    | | |
| | +----------------------------------------+ | |
| | +----------------------------------------+ | |
| | | [4]                                    | | |
| | +----------------------------------------+ | |
| +--------------------------------------------+ |
+------------------------------------------------+
```

## エレメント

### [1] 画面タイトル

- 概要: 未完了ジョブ一覧画面の見出し。
- 表示内容: `未完了ジョブ`
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `incomplete-job-list-title`
  - `aria-label`: なし。

### [2] ジョブ一覧領域

- 概要: 未完了ジョブを表示する領域。
- 表示内容: 未完了ジョブの一覧を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `incomplete-job-list-region`
  - `aria-label`: `未完了ジョブ一覧`

### [3] ジョブ行

- 概要: 未完了ジョブを選択する一覧。
- 表示内容: ジョブ名、更新日時、現在の翻訳段階を表示する。
- 依存情報:
  - 表示条件: 未完了ジョブが 1 件以上ある。
  - 有効条件: ジョブが再開可能な状態である。
  - 無効条件: ジョブが実行中の場合は選択できない。
- 操作: ジョブ行を選択する。
- 結果: 選択したジョブの再開先を決める。
- セレクタ属性:
  - `data-testid`: `incomplete-job-row`
  - `aria-label`: `未完了ジョブを選択する`

### [4] 再開ボタン

- 概要: 選択したジョブの作業を再開するボタン。
- 表示内容: `再開`
- 依存情報:
  - 表示条件: 未完了ジョブが 1 件以上ある。
  - 有効条件: 再開可能なジョブが選択されている。
  - 無効条件: ジョブ未選択、または選択中ジョブが実行中である。
- 操作: ボタンを押す。
- 結果: 選択したジョブの次に必要な翻訳画面へ遷移する。
- セレクタ属性:
  - `data-testid`: `resume-job-button`
  - `aria-label`: `未完了ジョブを再開する`
