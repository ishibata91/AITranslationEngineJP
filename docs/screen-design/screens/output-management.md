# 画面設計: 出力管理

- 目的: 完了済みジョブの出力準備、出力先、出力結果、差分内容を確認し、xTranslator XML の出力または再出力を行う。

## ワイヤーフレーム

```text
+------------------------------------------------+
| [1]                                            |
+------------------------------------------------+
| +------------+ +------------+ +--------------+ |
| | [2]        | | [3]        | | [4]          | |
| |            | |            | | +----------+ | |
| |            | |            | | | [5]      | | |
| |            | |            | | +----------+ | |
| +------------+ +------------+ +--------------+ |
| +--------------------------------------------+ |
| | [6]                                        | |
| +--------------------------------------------+ |
```

## エレメント

### [1] 出力管理概要

- 概要: 出力管理画面の目的、接続状態、画面状態を示す領域。
- 表示内容: `output-management`、`Output Review`、`Gateway` の状態、完了済みジョブ、結果要約、差分プレビュー、成果物状態、xTranslator XML の出力と再出力を確認する説明文、状態タイトル、状態説明、準備中の案内を表示する。
- 依存情報:
  - 表示条件: 出力管理画面が表示されている。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `output-management-output-management-summary`
  - `aria-label`: なし。

### [2] 出力候補

- 概要: XML 出力の候補になる完了済みジョブを一覧で表示し、対象ジョブを選択する領域。
- 表示内容: `completed job list`、`出力候補`、`更新`、ジョブ ID、成果物状態、ジョブ状態、翻訳済み件数、出力状態の分布を表示する。候補がない場合は、完了済みジョブがないことと、対象件数 0 のジョブが一覧に出ないことを表示する。
- 依存情報:
  - 表示条件: 出力管理画面が表示されている。
  - 有効条件: 完了済みジョブが 1 件以上ある場合、ジョブを選択できる。画面が読み込み中または送信中ではない場合、更新できる。
  - 無効条件: 画面が読み込み中または送信中の場合、更新できない。完了済みジョブがない場合、ジョブを選択できない。
- 操作: 更新ボタンを押す。出力候補のジョブを選択する。
- 結果: 更新ボタンを押すと、完了済みジョブ一覧を再取得する。ジョブを選択すると、選択中ジョブの要約、出力操作、差分プレビューを更新する。
- セレクタ属性:
  - `data-testid`: `output-management-output-candidate-list`
  - `aria-label`: なし。

### [3] 選択中ジョブ

- 概要: 選択した完了済みジョブの出力準備状態と拒否理由を表示する領域。
- 表示内容: `selected job summary`、`選択中 job` または `job 選択待ち`、画面状態、ジョブ ID、ジョブ状態、本文翻訳段階の状態、出力準備可否、翻訳済み件数、行数、成果物状態、現行版かどうか、入力 snapshot digest、ソースファイル digest、拒否理由を表示する。未選択の場合は、出力候補から完了済みジョブを選ぶ案内を表示する。
- 依存情報:
  - 表示条件: 出力管理画面が表示されている。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `output-management-selected-job`
  - `aria-label`: なし。

### [4] 出力操作

- 概要: 選択中ジョブの XML 出力条件を入力し、出力または再出力を実行する領域。
- 表示内容: `action rail`、`出力操作`、対象ゲーム、出力先 path、出力先 path の説明またはエラー理由、`XML を出力`、`再出力`、操作できない理由を表示する。対象ゲームの選択肢は `Skyrim SE` と `Skyrim LE` を表示する。
- 依存情報:
  - 表示条件: 出力管理画面が表示されている。
  - 有効条件: 出力可能なジョブが選択され、出力先 path が有効で、画面が送信中ではない場合、`XML を出力` を押せる。再出力可能な成果物があり、出力先 path が有効で、画面が送信中ではない場合、`再出力` を押せる。
  - 無効条件: ジョブ未選択、出力準備不可、出力先 path 不正、成果物なし、再出力不要、または送信中の場合は操作できない。禁止理由がある場合は理由を表示する。
- 操作: 対象ゲームを選択する。出力先 path を入力する。`XML を出力` または `再出力` を押す。
- 結果: 対象ゲームまたは出力先 path を変更すると、出力可否を更新する。出力または再出力を実行すると、直近結果と成果物状態を更新する。
- セレクタ属性:
  - `data-testid`: `output-management-output-actions`
  - `aria-label`: なし。

### [5] 直近結果

- 概要: 直近の出力または再出力の結果を表示する領域。
- 表示内容: `result summary`、成果物状態、行数、ファイル path、対象ゲーム、エラー理由を表示する。
- 依存情報:
  - 表示条件: 直近の出力または再出力の結果がある。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `output-management-latest-result`
  - `aria-label`: なし。

### [6] 差分プレビュー

- 概要: 選択中ジョブの翻訳単位ごとに、元文、訳文、出力状態、反映結果を比較する領域。
- 表示内容: `diff preview`、`translation unit 差分`、互換性要約、`Source`、`Dest`、`Status`、`row reflection summary`、EditorID、FormID、原文抜粋、訳文抜粋、内部出力状態、xTranslator 状態、行反映要約、古い成果物になった理由、再出力可否を表示する。差分がない場合は、差分プレビューが未取得である理由を表示する。
- 依存情報:
  - 表示条件: 出力管理画面が表示されている。
  - 有効条件: 差分プレビューがあり、行が 1 件以上ある場合、行を選択できる。
  - 無効条件: 成果物がない、行数が 0、gateway 未接続、または差分プレビュー未取得の場合は行を選択できない。
- 操作: 差分行を選択する。
- 結果: 選択中成果物 ID を差分プレビューの成果物 ID に更新する。
- セレクタ属性:
  - `data-testid`: `output-management-diff-preview`
  - `aria-label`: なし。
