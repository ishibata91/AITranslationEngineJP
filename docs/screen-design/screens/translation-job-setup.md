# 画面設計: 翻訳ジョブ設定

- 目的: 登録済みの入力データを選び、翻訳段階ごとの AI サービス、モデル、処理方式を確認して、翻訳ジョブを作成できる状態にする。

- 概要: 入力データ、共通基盤、AI 設定、作成前確認をまとめる領域。

- 結果: 子要素ごとの結果に従う。
- セレクタ属性:
  - `data-testid`: `translation-job-setup-pre-create-settings-region`
  - `aria-label`: なし。

### [3] 入力データ領域

- 概要: 登録済み入力データを選択し、選択中の入力データ詳細と既存ジョブ状態を確認する領域。
- 表示内容: `入力データ`、入力データ候補、入力データ名、出自、翻訳レコード件数、登録日時、削除状態、選択状態、既存 job 状態を表示する。
- 依存情報:
  - 表示条件: 作成前設定領域が表示されている。
  - 有効条件: 作成中ではなく、削除中ではない入力データ候補を選択できる。削除中の入力データがない場合、入力データ候補を削除できる。
  - 無効条件: 作成中の場合、入力データ選択と削除は操作できない。いずれかの入力データが削除中の場合、削除操作は操作できない。
- 操作: 入力データ候補を選択する。入力データ候補の `削除` を押す。
- 結果: 入力データを選択すると、選択中の入力データ詳細と既存 job 状態が更新される。削除すると、対象候補に `削除中...` を表示し、削除後に候補一覧が更新される。
- セレクタ属性:
  - `data-testid`: `translation-job-setup-input-data-region`
  - `aria-label`: `input data`

### [5] AI サービスとモデル領域

- 概要: 単語翻訳、NPC ペルソナ生成、本文翻訳ごとに AI サービス、モデル、API キー状態、処理方式を選ぶ領域。
- 表示内容: `AI サービスとモデル`、`単語翻訳`、`NPC ペルソナ生成`、`本文翻訳`、各段階の状態、補足文、`AIサービス`、API キー状態、API キー警告、`モデル`、モデル一覧更新ボタン、モデル一覧状態、`処理方式`、`Batch API`、処理方式の補足、現在の状態、実行方法を表示する。
- 依存情報:
  - 表示条件: 作成前設定領域が表示され、翻訳段階ごとの設定カードがある場合に表示する。
  - 有効条件: 作成中ではない場合、AI サービスを選択できる。モデル一覧が利用可能で候補が 1 件以上あり、API キーが不足していない場合、モデルを選択できる。モデル一覧更新ボタンが有効な場合、モデル一覧を更新できる。作成中ではない場合、対応する AI サービスでは `Batch API` を切り替えできる。
  - 無効条件: 作成中の場合、AI サービス、モデル、`Batch API` は操作できない。API キーが未設定の場合、モデル選択は操作できない。モデル一覧が未更新、更新中、取得失敗、または候補 0 件の場合、モデル選択は操作できない。`Batch API` 非対応の AI サービスでは切り替えを表示しない。
- 操作: AI サービスを選択する。モデル一覧を更新する。モデルを選択する。`Batch API` を切り替える。
- 結果: AI サービスを選択すると、モデル選択と API キー状態が更新される。モデル一覧を更新すると、モデル候補とモデル一覧状態が更新される。モデルを選択すると、段階の現在状態が更新される。`Batch API` を切り替えると、実行方法が有効または無効に更新される。
- セレクタ属性:
  - `data-testid`: `translation-job-setup-ai-service-model-region`
  - `aria-label`: 各段階のモデル一覧更新ボタンは `<翻訳段階>のモデル一覧を更新`

### [6] 互換設定と作成前確認領域

- 概要: 翻訳段階ごとの設定を取得できない場合に、従来形式の AI 実行設定と作成前確認を表示する領域。
- 表示内容: `翻訳段階別設定`、`phase settings unavailable`、`AIサービス / モデル / 実行方法`、翻訳段階別設定を取得できない説明文、`作成前確認`、`pre-check`、`確認を実行`、状態、確認日時、作成できない理由、再確認、確認対象、確認済み項目を表示する。
- 依存情報:
  - 表示条件: 作成前設定領域が表示され、翻訳段階ごとの設定カードがない場合に表示する。
  - 有効条件: 入力データが選択され、AI 実行設定が選択され、資格情報参照があり、作成前確認を実行できる状態の場合、`確認を実行` を操作できる。
  - 無効条件: 入力データ、AI 実行設定、資格情報参照、または作成前確認の実行条件が不足している場合、`確認を実行` は操作できない。
- 操作: `AIサービス / モデル / 実行方法` を選択する。`確認を実行` を押す。
- 結果: AI 実行設定を選択すると、作成前確認の要否が更新される。作成前確認を実行すると、状態、確認日時、作成できない理由、再確認、確認対象、確認済み項目が更新される。
- セレクタ属性:
  - `data-testid`: `translation-job-setup-compatibility-precheck-region`
  - `aria-label`: なし。

### [7] ジョブ作成固定フッター

- 概要: 作成前設定の不足理由を確認し、翻訳ジョブを作成して次の翻訳段階へ進む固定フッター。
- 表示内容: `ジョブの作成確認`、入力データと翻訳設定を確認して最初の翻訳段階へ進む準備をする説明文、不足理由、`ほか <件数> 件の確認が必要です`、`確認が必要な項目`、`作成に必要な確認は完了しています。`、`作成前に確認が必要な項目があります。`、`入力データの再構築が必要です。入力データの確認画面に戻ってください。`、`入力データの確認へ戻る`、`単語翻訳へ進む` を表示する。
- 依存情報:
  - 表示条件: 作成前設定領域が表示されている。
  - 有効条件: 作成可能な場合、`単語翻訳へ進む` を操作できる。入力データの再構築案内があり、戻り操作が渡されている場合、`入力データの確認へ戻る` を操作できる。
  - 無効条件: 作成できない理由がある場合、`単語翻訳へ進む` は操作できない。
- 操作: `単語翻訳へ進む` を押す。必要な場合は `入力データの確認へ戻る` を押す。不足理由が複数ある場合、残り理由のツールチップを確認する。
- 結果: `単語翻訳へ進む` を押すと、翻訳ジョブを作成する。作成後は作成済み要約を表示する。`入力データの確認へ戻る` を押すと、入力データの確認画面へ戻る。
- セレクタ属性:
  - `data-testid`: `translation-job-setup-job-create-sticky-footer`
  - `aria-label`: `ジョブの作成確認: 入力データと翻訳設定を確認し、最初の翻訳段階へ進む準備をします。`
