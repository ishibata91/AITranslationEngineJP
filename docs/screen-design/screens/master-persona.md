# 画面設計: マスターペルソナ

- 目的: 入力 JSON と AI 設定からマスターペルソナを作成し、作成済みペルソナの検索、確認、編集、削除を行う。

## ワイヤーフレーム

```text
+------------------------------------------------+
| [1]                                            |
| +--------------------------------------------+ |
| | [2]                                        | |
| | +------------------+ +-------------------+ | |
| | | [3]              | | [4]               | | |
| | +------------------+ +-------------------+ | |
| +--------------------------------------------+ |
| +--------------------------------------------+ |
| | [5]                                        | |
| +--------------------------------------------+ |
| +---------------------+ +--------------------+ |
| | [6]                 | | [7]                | |
| +---------------------+ +--------------------+ |
| +--------------------------------------------+ |
| | [8]                                        | |
| +--------------------------------------------+ |
| +--------------------------------------------+ |
| | [9]                                        | |
| +--------------------------------------------+ |
+------------------------------------------------+
```

## エレメント

### [1] 画面状態領域

- 概要: 画面名、現在フェーズ、状態、件数を共通の状態パネルで表示する領域。
- 表示内容: `マスターペルソナ`、現在フェーズ、状態要約、件数、gateway 接続状態、通知メッセージを表示する。画面見出しは読み上げ用に表示する。
- 依存情報:
  - 表示条件: 画面を開いている間は作成状態を常に表示する。通知メッセージはエラーまたは AI 設定メッセージがある場合だけ表示する。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `master-persona-screen-status-region`
  - `aria-label`: `マスターペルソナ作成状態`

### [2] 生成準備パネル

- 概要: JSON 入力パネルを状態パネル直下に表示し、その下に進行状況と AI 設定を横並びで表示する領域。
- 表示内容: JSON 入力パネル、進行状況パネル、AI 設定パネルを表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `master-persona-generation-setup-panel`
  - `aria-label`: なし。

### [3] AI 設定カード

- 概要: AI 設定カード自体をパネルとして表示する領域。
- 表示内容: AI サービス、モデル、実行方法、資格情報の状態、資格情報の警告、`モデル一覧を更新`、`設定を保存` を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: AI 設定の更新中でない場合に、AI サービス、実行方法、モデル一覧更新、設定保存を操作できる。モデル選択はモデル選択可能状態の場合だけ操作できる。
  - 無効条件: AI 設定の更新中は操作できない。モデル一覧が未取得または設定不足の場合はモデルを選択できない。
- 操作: AI サービスを選択する。モデルを選択する。実行方法を選択する。モデル一覧を更新する。設定を保存する。
- 結果: 選択中の AI 設定、モデル一覧、資格情報状態、設定保存結果が画面に反映される。
- セレクタ属性:
  - `data-testid`: `master-persona-ai-settings-card`
  - `aria-label`: `モデル一覧を更新`

### [4] 入力 JSON パネル

- 概要: 共通のファイル入力パネルで JSON ファイルの選択状態と生成対象件数を表示する領域。
- 表示内容: `入力 JSON`、選択中ファイル名、説明文、候補数、新規作成数、既存スキップ数、`JSON を選択`、`選び直す`、`ペルソナを作成` を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: `JSON を選択` は常に操作できる。`選び直す` は JSON が選択済みの場合だけ操作できる。`ペルソナを作成` は作成開始可能状態の場合だけ操作できる。
  - 無効条件: JSON が未選択の場合は `選び直す` を操作できない。JSON、AI 設定、作成可能件数、実行状態のいずれかが作成開始条件を満たさない場合は `ペルソナを作成` を操作できない。
- 操作: JSON ファイルを選択する。選択済み JSON を取り消す。ペルソナ作成を開始する。
- 結果: 選択ファイル名、作成対象件数、作成状態、進行状況が更新される。
- セレクタ属性:
  - `data-testid`: `master-persona-input-json-panel`
  - `aria-label`: `対象件数`

### [5] 進行状況パネル

- 概要: JSON 入力パネルの下で、AI 設定パネルと横並びに進行状況を表示する領域。
- 表示内容: `進行状況`、進行メッセージ、実行中の編集禁止説明、状態値、進捗バー、処理済み件数、作成済み件数、既に作成済み、現在の対象、`一時停止`、`中止` を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: `一時停止` と `中止` は生成中の場合だけ操作できる。
  - 無効条件: 生成中でない場合は `一時停止` と `中止` を操作できない。
- 操作: 生成を一時停止する。生成を中止する。
- 結果: 実行状態、進捗、処理件数、現在の対象、一覧と詳細の操作可否が更新される。
- セレクタ属性:
  - `data-testid`: `master-persona-progress-panel`
  - `aria-label`: `生成進捗`

### [6] 生成結果一覧パネル

- 概要: マスターペルソナを処理対象一覧として検索、絞り込み、確認、操作する領域。
- 表示内容: `ペルソナ一覧`、検索欄、プラグイン絞り込み、件数、ページ操作、処理対象一覧、metadata、行操作を表示する。metadata は `FormID`、`EditorID`、`対象プラグイン`、`元プラグイン`、`声`、`話し方`、`ペルソナ本文`、`最終更新` を表示する。行操作は編集と削除を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: 検索入力とプラグイン選択は常に操作できる。ペルソナ行は一覧項目がある場合に操作できる。`前へ` は 2 ページ目以降で操作できる。`次へ` は最終ページより前で操作できる。
  - 無効条件: 一覧項目がない場合は空状態を表示する。先頭ページでは `前へ` を操作できない。最終ページでは `次へ` を操作できない。
- 操作: 検索語を入力する。プラグインを選択する。ペルソナ行を開く。編集または削除を開始する。ページを切り替える。
- 結果: 条件に一致するペルソナ一覧を表示する。開いたペルソナ行に metadata、ペルソナ本文、編集、削除を表示する。モーダルを表示する。
- セレクタ属性:
  - `data-testid`: `master-persona-generation-result-list-panel`
  - `aria-label`: `生成結果の確認`、`ペルソナ一覧のページ操作`

### [7] ペルソナ詳細パネル

- 概要: 選択中ペルソナの識別情報、属性、本文を確認し、編集または削除を開始する領域。
- 表示内容: `詳細`、選択中ペルソナ名、`編集`、`削除`、FormID、EditorID、対象プラグイン、元プラグイン、声、話し方、ペルソナ本文を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: `編集` と `削除` は選択中ペルソナがあり、変更可能状態の場合だけ操作できる。
  - 無効条件: ペルソナ未選択または生成中などの変更不可状態では `編集` と `削除` を操作できない。
- 操作: 編集を開始する。削除を開始する。
- 結果: 編集モーダルまたは削除モーダルを表示する。
- セレクタ属性:
  - `data-testid`: `master-persona-persona-detail-panel`
  - `aria-label`: なし。

### [8] 編集モーダル

- 概要: 選択中ペルソナの要約、話し方、本文を編集して保存するモーダル。
- 表示内容: `編集`、`ペルソナを編集`、選択中ペルソナ名、対象プラグイン、EditorID、ペルソナ要約、話し方、ペルソナ本文、`閉じる`、`キャンセル`、`編集内容を保存` を表示する。
- 依存情報:
  - 表示条件: 編集モーダル状態の場合だけ表示する。
  - 有効条件: 入力欄、`閉じる`、`キャンセル`、`編集内容を保存` はモーダル表示中に操作できる。
  - 無効条件: 編集モーダル状態でない場合は表示しない。
- 操作: ペルソナ要約を入力する。話し方を入力する。ペルソナ本文を入力する。編集を閉じる。編集をキャンセルする。編集内容を保存する。
- 結果: 保存した内容が選択中ペルソナと一覧に反映される。閉じるまたはキャンセルではモーダルを閉じる。
- セレクタ属性:
  - `data-testid`: `master-persona-edit-modal`
  - `aria-label`: なし。

### [9] 削除モーダル

- 概要: 選択中ペルソナの識別情報を確認し、削除を実行するモーダル。
- 表示内容: `削除`、`ペルソナを削除しますか`、削除説明、名前、FormID、EditorID、対象プラグイン、`閉じる`、`キャンセル`、`削除する` を表示する。
- 依存情報:
  - 表示条件: 削除モーダル状態の場合だけ表示する。
  - 有効条件: `閉じる`、`キャンセル`、`削除する` はモーダル表示中に操作できる。
  - 無効条件: 削除モーダル状態でない場合は表示しない。
- 操作: 削除を閉じる。削除をキャンセルする。削除する。
- 結果: 削除したペルソナを一覧から外す。閉じるまたはキャンセルではモーダルを閉じる。
- セレクタ属性:
  - `data-testid`: `master-persona-delete-modal`
  - `aria-label`: なし。
