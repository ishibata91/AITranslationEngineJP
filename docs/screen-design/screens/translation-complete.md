# 画面設計: 翻訳完了確認

- 目的: 本文翻訳が完了したジョブについて、原文と訳文を確認し、出力管理へ進む。

## ワイヤーフレーム

```text
+------------------------------------------------+
| [1]                                            |
| +--------------------------------------------+ |
| | [2]                                        | |
| +--------------------------------------------+ |
| +--------------------------------------------+ |
| | [3]                                        | |
| | +----------------------------------------+ | |
| | | [4]                                    | | |
| | +----------------------------------------+ | |
| | +----------------------------------------+ | |
| | | [5]                                    | | |
| | +----------------------------------------+ | |
| | +----------------------------------------+ | |
| | | [6]                                    | | |
| | +----------------------------------------+ | |
| +--------------------------------------------+ |
+------------------------------------------------+
| [7]                                            |
+------------------------------------------------+
```

## エレメント

### [1] 翻訳完了確認画面

- 概要: 本文翻訳後の確認内容と、次の作業への導線をまとめる画面。
- 表示内容: 完了概要、原文と訳文、翻訳結果ページング、翻訳完了後の次の作業を表示する。
- 依存情報:
  - 表示条件: 選択ジョブがあり、本文翻訳段階の画面状態があり、翻訳実行シェルの現在段階が翻訳完了確認である。
  - 有効条件: なし。
  - 無効条件: 選択ジョブがない場合、または本文翻訳段階の画面状態がない場合は表示しない。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `translation-complete-translation-complete-screen`
  - `aria-label`: なし。

### [2] 完了概要

- 概要: 翻訳完了確認の対象ジョブと画面の役割を示す領域。
- 表示内容: `translation complete`、`翻訳完了`、ジョブID、本文翻訳が完了したジョブの原文と訳文を確認する説明、成果物の出力処理は出力管理で扱う説明を表示する。
- 依存情報:
  - 表示条件: 翻訳完了確認画面が表示されている。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `translation-complete-completion-summary`
  - `aria-label`: なし。

### [3] 処理対象一覧領域

- 概要: 翻訳完了確認で確認する実体を、処理対象一覧として表示する領域。
- 表示内容: `処理対象`、現在段階名 `翻訳結果の確認`、処理対象名、処理対象詳細、原文、訳文、件数、ページ操作を表示する。処理対象名は翻訳項目単位の訳文である。処理対象詳細は、本文翻訳で保持された訳文として出力管理へ進む前に確認するものとして表示する。
- 依存情報:
  - 表示条件: 翻訳完了確認画面が表示されている。
  - 有効条件: 翻訳結果行または空状態を表示できる。
  - 無効条件: なし。
- 操作: 処理対象行を開く。ページを切り替える。
- 結果: 処理対象行の metadata を表示する。表示する処理対象の範囲が切り替わる。
- セレクタ属性:
  - `data-testid`: `translation-complete-source-translation-region`
  - `aria-label`: `処理対象一覧`

### [4] 翻訳結果行

- 概要: 1 件の翻訳対象 field の原文と訳文を確認する行。
- 表示内容: レコード種別ラベル、field ラベル、出力状態、`原文`、原文抜粋、`訳文`、訳文を表示する。
- 依存情報:
  - 表示条件: 表示中ページに翻訳結果が 1 件以上ある。
  - 有効条件: `原文` と `訳文` は開閉できる。
  - 無効条件: 表示中ページに翻訳結果がない場合は表示しない。
- 操作: `原文` または `訳文` を開閉する。
- 結果: 対象の原文抜粋または訳文の表示と非表示が切り替わる。
- セレクタ属性:
  - `data-testid`: `translation-complete-translation-result-row`
  - `aria-label`: なし。

### [5] 翻訳結果空状態

- 概要: 表示できる翻訳結果がないことを示す領域。
- 表示内容: `表示できる翻訳結果がありません。`
- 依存情報:
  - 表示条件: 表示中ページに翻訳結果がない。
  - 有効条件: なし。
  - 無効条件: 表示中ページに翻訳結果がある場合は表示しない。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `translation-complete-translation-result-empty-state`
  - `aria-label`: なし。

### [6] 翻訳結果ページング

- 概要: 翻訳結果の表示ページを切り替える操作領域。
- 表示内容: `前へ`、現在ページ、総ページ数、`次へ` を表示する。
- 依存情報:
  - 表示条件: 翻訳完了確認画面が表示されている。
  - 有効条件: `前へ` は 2 ページ目以降で押せる。`次へ` は最終ページより前で押せる。
  - 無効条件: `前へ` は 1 ページ目では押せない。`次へ` は最終ページでは押せない。
- 操作: `前へ` または `次へ` を押す。
- 結果: 表示する翻訳結果のページが切り替わる。
- セレクタ属性:
  - `data-testid`: `translation-complete-translation-result-pagination`
  - `aria-label`: `翻訳結果ページング`

### [7] 翻訳完了後の次の作業

- 概要: 翻訳結果確認後に出力管理へ進む固定フッター。
- 表示内容: `翻訳完了後の次の作業`、翻訳結果を確認した後は出力管理で出力対象を選ぶ説明、`未完了一覧へ戻る`、`出力管理へ進む` を表示する。
- 依存情報:
  - 表示条件: 翻訳完了確認画面が表示されている。
  - 有効条件: `未完了一覧へ戻る` と `出力管理へ進む` は常に押せる。
  - 無効条件: なし。
- 操作: `未完了一覧へ戻る` を押す。`出力管理へ進む` を押す。
- 結果: `未完了一覧へ戻る` を押すと、未完了ジョブ一覧を表示する。`出力管理へ進む` を押すと、出力管理を表示する。
- セレクタ属性:
  - `data-testid`: `translation-complete-post-completion-next-action`
  - `aria-label`: 見出しと説明を連結した文言。
