- 概要: 本文翻訳段階に対して実行できる操作を並べる領域。
- 表示内容: `操作`、現在の翻訳段階、`開始`、`中断`、`再開`、`リトライ`、`キャンセル`、`出力準備を確認`、`更新`、無効な操作の理由を表示する。
- 依存情報:
  - 表示条件: 本文翻訳段階画面が表示されている。
  - 有効条件: 選択中ジョブ、本文翻訳段階の状態、実行中操作、操作可否情報が操作を許可している。
  - 無効条件: ジョブ未選択、読み込み中、送信中、または操作可否情報が操作を禁止している場合は押せない。禁止理由がある場合は、操作名と理由を表示する。
- 操作: 操作ボタンを押す。
- 結果: 対象操作の結果に応じて、本文翻訳段階の状態、進行状況、失敗情報、後続出力準備状態を更新する。
