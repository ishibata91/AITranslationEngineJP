# 画面設計: 翻訳入力レビュー

- 目的: xEdit の JSON を登録し、読み込み済みデータの登録結果、概要、問題、再構築要否を確認して、翻訳設定へ進む。

## ワイヤーフレーム

```text
+------------------------------------------------+
| [1]                                            |
| +--------------------------------------------+ |
| | [2]                                        | |
| +--------------------------------------------+ |
| +---------------------+ +--------------------+ |
| | [3]                 | | [4]                | |
| |                     | | +----------------+ | |
| |                     | | | [5]            | | |
| |                     | | +----------------+ | |
| |                     | | +----------------+ | |
| |                     | | | [6]            | | |
| |                     | | +----------------+ | |
| +---------------------+ +--------------------+ |
| [7]                                            |
+------------------------------------------------+
```

## エレメント

### [1] 画面状態ヘッダー

- 概要: 翻訳入力レビュー画面の目的と現在の作業状態を示す領域。
- 表示内容: `翻訳管理`、`データロード`、`JSON を読み込み、登録結果と再構築の要否を同じ画面で確認する。`、接続状態、作業状態、作業状態の説明、エラーメッセージを表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: `現在の作業状態`

### [2] ロード準備領域

- 概要: 登録前の JSON を選び、ファイル情報を確認して登録する領域。
- 表示内容: `ロード準備`、説明文、選択状態、ファイル名、保存場所、内容ハッシュ、`ロード対象を選ぶ`、`この JSON を登録`、`選び直す` を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: `ロード対象を選ぶ` は登録中以外に操作できる。`この JSON を登録` は登録対象ファイルがあり、登録待ち状態の時に操作できる。`選び直す` は登録対象ファイルがあり、登録中ではない時に操作できる。
  - 無効条件: 登録対象ファイルがない場合、登録操作と選び直しはできない。登録中の場合、ファイル選択と選び直しはできない。
- 操作: JSON を選ぶ。選んだ JSON を登録する。選択中の JSON を取り消す。
- 結果: JSON を選ぶとファイル名、保存場所、内容ハッシュ、選択状態が更新される。登録すると読み込み済みデータ一覧と選択データ詳細が更新される。選び直すと登録前のファイル情報が未選択へ戻る。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [3] 読み込み済みデータ一覧

- 概要: 登録済みの JSON を選択し、状態と登録結果を確認する一覧。
- 表示内容: `読み込み済みデータ`、保持件数、空状態文、ファイル名、保存場所、登録状態、登録結果、再構築可否、読み込み日時、内容ハッシュ、問題区分を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: 読み込み済みデータが 1 件以上ある場合、各行を選択できる。
  - 無効条件: 読み込み済みデータがない場合、一覧行は表示しない。
- 操作: 読み込み済みデータの行を選択する。
- 結果: 選択データ詳細が、選択した読み込み済みデータの内容に更新される。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [4] 選択データ領域

- 概要: 一覧で選択した読み込み済みデータの内容と直近結果を表示する領域。
- 表示内容: `選択データの内容`、選択状態、直近結果、未選択時の案内、翻訳設定へ進める場合の `次の手順` を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: 読み込み済みデータが選択されている場合、概要、カテゴリ別件数、サンプル項目、問題と再構築を表示する。選択データの状態が `登録済み` または `警告あり` の場合、翻訳設定へ進む前の案内を表示する。
  - 無効条件: 読み込み済みデータが未選択の場合、詳細情報は表示しない。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [5] 入力データ概要

- 概要: 選択した読み込み済みデータの基本情報、集計、サンプル項目を表示する領域。
- 表示内容: ファイル名、保存場所、内容ハッシュ、読み込み日時、翻訳レコード数、翻訳フィールド数、対象プラグイン、抽出元ツール、カテゴリ別件数、サンプル項目、`Form ID`、`Editor ID`、翻訳対象かどうかを表示する。
- 依存情報:
  - 表示条件: 読み込み済みデータが選択されている。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [6] 問題と再構築領域

- 概要: 登録エラー、警告、再構築可否を確認し、必要な場合に再構築する領域。
- 表示内容: `問題と再構築`、説明文、`cache を再構築`、登録時の問題区分、再構築の可否、警告、問題なしの案内を表示する。
- 依存情報:
  - 表示条件: 読み込み済みデータが選択されている。
  - 有効条件: 選択データが再構築可能で、再構築中ではない時に `cache を再構築` を操作できる。
  - 無効条件: 選択データが再構築不可、または再構築中の場合は `cache を再構築` を操作できない。
- 操作: `cache を再構築` を押す。
- 結果: 再構築中の作業状態を表示する。再構築結果に応じて登録結果、警告、問題区分、再構築可否を更新する。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [7] 次の作業フッター

- 概要: 選択済みの読み込み済みデータから翻訳設定へ進む固定フッター。
- 表示内容: `次の作業`、`入力データを選択済みです。次に翻訳設定を確認します。`、`翻訳設定へ進む` を表示する。
- 依存情報:
  - 表示条件: 選択データの状態が `登録済み` または `警告あり` の場合に表示する。
  - 有効条件: 表示されている場合に操作できる。
  - 無効条件: 選択データが未選択、`登録失敗`、または `再構築が必要` の場合は表示しない。
- 操作: `翻訳設定へ進む` を押す。
- 結果: 選択した入力データで翻訳設定の確認へ進む。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: `次の作業: 選択した入力データで、ジョブの作成確認へ進みます。`
