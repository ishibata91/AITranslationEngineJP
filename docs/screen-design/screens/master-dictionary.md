# 画面設計: マスター辞書

- 目的: Skyrim Mod 向け翻訳の基盤データとして使うマスター辞書を検索し、詳細確認、登録、更新、削除、XML 取り込みを同じ画面で行う。

## エレメント

### [1] マスター辞書画面

- 概要: マスター辞書画面全体の領域。
- 表示内容: 上部状態パネル、XML 入力パネル、XML 取り込み進行状況パネル、処理対象一覧として表示する辞書一覧、新規登録、更新、削除のモーダルを縦に表示する。
- 依存情報:
  - 表示条件: マスター辞書画面を開いている。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `master-dictionary-master-dictionary-screen`
  - `aria-label`: なし。

### [2] 上部状態パネル

- 概要: 画面名、現在フェーズ、状態、件数を共通の状態パネルで表示する領域。
- 表示内容: `マスター辞書`、現在のフェーズ `マスター辞書管理`、状態要約、件数、gateway 接続状態、エラーメッセージを表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `master-dictionary-screen-header`
  - `aria-label`: なし。

### [3] XML 入力パネル

- 概要: 共通のファイル入力パネルで XML ファイルの選択状態を表示する領域。
- 表示内容: `XMLから取り込み`、`ファイルを選択`、選択ファイル名、補助情報、XML 待機説明を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: 取り込み中ではない。
  - 無効条件: 取り込み中はファイル選択と選び直しを操作できない。
- 操作: `ファイルを選択` を押して XML ファイルを選ぶ。
- 結果: 選択ファイル名を表示し、取り込みバーを表示する。
- セレクタ属性:
  - `data-testid`: `master-dictionary-xml-import-region`
  - `aria-label`: なし。

### [4] XML 取り込み進行状況パネル

- 概要: 選択済み XML の取り込み実行、進捗、結果を表示する領域。
- 表示内容: 選択ファイル名、`この XML を取り込む`、`選び直す`、取込状態値、進捗バー、取り込み結果を表示する。
- 依存情報:
  - 表示条件: XML ファイルが選択されている。
  - 有効条件: 取り込み中ではない。
  - 無効条件: 取り込み中は取り込み開始と選び直しを操作できない。
- 操作: `この XML を取り込む` を押す。`選び直す` を押す。
- 結果: 取り込み開始時は進捗を更新する。取り込み完了時は一覧、詳細、結果件数を同じ画面へ反映する。選び直し時は選択ファイルを解除する。
- セレクタ属性:
  - `data-testid`: `master-dictionary-xml-import-bar`
  - `aria-label`: なし。

### [5] 辞書操作領域

- 概要: 辞書一覧と詳細を横並びで表示する領域。
- 表示内容: 左側に辞書一覧、右側に選択中エントリの詳細を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `master-dictionary-dictionary-operation-region`
  - `aria-label`: なし。

### [6] 辞書一覧パネル

- 概要: マスター辞書エントリを処理対象一覧として検索、絞り込み、確認、操作する領域。
- 表示内容: `辞書一覧`、検索欄、カテゴリ絞り込み、操作ボタン、選択サマリ、件数、ページ操作、処理対象一覧、metadata、行操作を表示する。metadata は `辞書 ID`、`カテゴリ`、`登録元`、`最終更新`、`メモ` を表示する。行操作は更新と削除を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: 検索語を入力する。カテゴリを選択する。新規登録を開始する。辞書行を開く。更新または削除を開始する。ページを切り替える。
- 結果: 条件に一致する辞書一覧を表示する。開いた辞書行に metadata と操作を表示する。モーダルを表示する。
- セレクタ属性:
  - `data-testid`: `master-dictionary-dictionary-list-panel`
  - `aria-label`: なし。

### [7] 一覧操作バー

- 概要: 新規登録、検索、カテゴリ絞り込みを行う領域。
- 表示内容: `新規登録`、`検索`、`原文・訳語・IDで検索`、`カテゴリ`、カテゴリ選択肢を表示する。カテゴリ選択肢には `すべて` とカテゴリ候補を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: 常に操作できる。
  - 無効条件: なし。
- 操作: `新規登録` を押す。検索文字列を入力する。カテゴリを選択する。
- 結果: 新規登録モーダルを開く。検索条件またはカテゴリ条件に合う一覧へ更新する。
- セレクタ属性:
  - `data-testid`: `master-dictionary-list-action-bar`
  - `aria-label`: なし。

### [8] 辞書一覧

- 概要: 条件に一致するマスター辞書エントリを処理対象一覧として表示し、詳細表示対象を選ぶ一覧。
- 表示内容: 見出しとして `訳語`、`原文`、`カテゴリ`、`ID` を表示する。各行に訳語、原文、カテゴリ、由来、ID を表示する。該当行がない場合は `一致するエントリがありません` を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: エントリが 1 件以上ある。
  - 無効条件: エントリが 0 件の場合は選択できる行がない。
- 操作: 一覧行を押す。
- 結果: 選択したエントリを詳細パネルへ表示する。
- セレクタ属性:
  - `data-testid`: `master-dictionary-dictionary-list`
  - `aria-label`: なし。

### [9] ページ操作領域

- 概要: 選択状態とページ移動を示す領域。
- 表示内容: 選択状態文、`前の30件`、`次の30件` を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: 前ページまたは次ページがある。
  - 無効条件: 先頭ページでは `前の30件` を操作できない。最終ページでは `次の30件` を操作できない。
- 操作: `前の30件` または `次の30件` を押す。
- 結果: 表示ページを変更し、一覧と選択状態を更新する。
- セレクタ属性:
  - `data-testid`: `master-dictionary-pagination-region`
  - `aria-label`: なし。

### [10] 詳細パネル

- 概要: 選択中エントリの内容を確認し、更新または削除へ進む領域。
- 表示内容: `詳細`、詳細補足文、`更新`、`削除`、カテゴリ、由来、原文、訳語、ID、最終更新、詳細状態文を表示する。選択中エントリがない場合は、表示できるエントリがないことと検索条件変更の案内を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: 選択中エントリがある。
  - 無効条件: 選択中エントリがない場合は `更新` と `削除` を操作できない。
- 操作: `更新` を押す。`削除` を押す。
- 結果: 更新モーダルまたは削除確認モーダルを開く。
- セレクタ属性:
  - `data-testid`: `master-dictionary-detail-panel`
  - `aria-label`: なし。

### [11] 新規登録・更新モーダル

- 概要: マスター辞書エントリを新規登録または更新する入力領域。
- 表示内容: 新規登録時は `新規登録` と `辞書エントリの内容を入力します。` を表示する。更新時は `更新` と `選択中の辞書エントリを編集します。` を表示する。入力項目として `原文`、`カテゴリ`、`由来`、`訳語` を表示する。操作として `閉じる` と `保存する` を表示する。
- 依存情報:
  - 表示条件: 新規登録または更新モーダルが開いている。
  - 有効条件: モーダルが開いている。
  - 無効条件: なし。
- 操作: 原文、カテゴリ、由来、訳語を入力または選択する。`閉じる` または `保存する` を押す。
- 結果: `閉じる` ではモーダルを閉じる。`保存する` では入力内容を保存し、一覧と詳細を更新する。
- セレクタ属性:
  - `data-testid`: `master-dictionary-create-edit-modal`
  - `aria-label`: なし。

### [12] 削除確認モーダル

- 概要: 選択中エントリの削除を確認する領域。
- 表示内容: `削除の確認`、削除すると一覧から見えなくなる説明、削除対象の原文、訳語、ID、`やめる`、`削除する` を表示する。
- 依存情報:
  - 表示条件: 削除確認モーダルが開いている。
  - 有効条件: 選択中エントリがある。
  - 無効条件: 選択中エントリがない場合は削除対象を `-` で表示する。
- 操作: `やめる` または `削除する` を押す。
- 結果: `やめる` ではモーダルを閉じる。`削除する` では選択中エントリを削除し、一覧と次の選択状態を更新する。
- セレクタ属性:
  - `data-testid`: `master-dictionary-delete-confirmation-modal`
  - `aria-label`: なし。
