# 画面設計: ダッシュボード

- 目的: 利用者が最初に移動したい主要ページを選び、共通ナビゲーションから主要ページへ切り替えられる入口を提供する。

## ワイヤーフレーム

```text
+------------------------------------------------+
| [1]                                            |
| +----------------+ +------------------------+  |
| | [2]            | | [3]                    |  |
| +----------------+ +------------------------+  |
+------------------------------------------------+
| [4]                                            |
| +--------------------------------------------+ |
| | [5]                                        | |
| +--------------------------------------------+ |
| +--------------------------------------------+ |
| | [6]                                        | |
| | +------------------+ +-------------------+ | |
| | | [7]              | | [7]               | | |
| | +------------------+ +-------------------+ | |
| | +------------------+ +-------------------+ | |
| | | [7]              | | [7]               | | |
| | +------------------+ +-------------------+ | |
| +--------------------------------------------+ |
+------------------------------------------------+
```

## エレメント

### [1] アプリケーションヘッダー

- 概要: アプリケーション名と主要ページ移動をまとめる固定ヘッダー。
- 表示内容: `AITranslationEngineJp`、`翻訳エンジン`、グローバルナビゲーション、モバイル用の `主要ページ` ボタンを表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `dashboard-application-header`
  - `aria-label`: なし。

### [2] ブランド表示

- 概要: 現在のアプリケーションを示すヘッダー左側の表示。
- 表示内容: `AITranslationEngineJp`、`翻訳エンジン`
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `dashboard-brand-display`
  - `aria-label`: なし。

### [3] グローバルナビゲーション

- 概要: 主要ページへ移動するナビゲーション。
- 表示内容: `ダッシュボード`、`AIサービス設定`、`マスター辞書`、`マスターペルソナ`、`翻訳管理`、`出力管理`
- 依存情報:
  - 表示条件: デスクトップ幅では常に表示する。モバイル幅では `主要ページ` ボタンで開いた時に表示する。
  - 有効条件: 各主要ページの route が存在する。
  - 無効条件: なし。
- 操作: 主要ページ名を押す。
- 結果: 選択した主要ページへ切り替わる。選択中の主要ページには現在地表示を付ける。
- セレクタ属性:
  - `data-testid`: `dashboard-global-navigation`
  - `aria-label`: `グローバルナビゲーション`

### [4] ダッシュボード本文

- 概要: 現在ページの説明と主要ページ入口を縦に並べる本文領域。
- 表示内容: 現在ページ説明領域、主要ページ入口領域を表示する。
- 依存情報:
  - 表示条件: 現在の route が `dashboard` である。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `dashboard-dashboard-content`
  - `aria-label`: なし。

### [5] 現在ページ説明

- 概要: ダッシュボードが現在表示中であることと、画面の使い方を示す領域。
- 表示内容: `現在のページ`、`ダッシュボード`、`最初に移動したい作業を選び、共通ナビゲーションからいつでも別の主要ページへ切り替えられます。`
- 依存情報:
  - 表示条件: 現在の route が `dashboard` である。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `dashboard-current-page-description`
  - `aria-label`: なし。

### [6] 主要ページ入口領域

- 概要: ダッシュボード以外の主要ページをカードで並べる領域。
- 表示内容: `主要ページ`、`作業を選ぶ`、主要ページカードを表示する。
- 依存情報:
  - 表示条件: 現在の route が `dashboard` である。
  - 有効条件: ダッシュボード以外の主要ページが 1 件以上ある。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `dashboard-primary-page-entry-region`
  - `aria-label`: なし。

### [7] 主要ページカード

- 概要: 主要ページごとの状態、説明、移動操作をまとめるカード。
- 表示内容: route の固定名、主要ページ名、状態、説明、`開く` を表示する。対象は `AIサービス設定`、`マスター辞書`、`マスターペルソナ`、`翻訳管理`、`出力管理` である。
- 依存情報:
  - 表示条件: 対象 route が `dashboard` 以外である。
  - 有効条件: 対象 route が存在する。
  - 無効条件: なし。
- 操作: カードを押す。
- 結果: 対象の主要ページへ切り替わる。
- セレクタ属性:
  - `data-testid`: `dashboard-primary-page-card`
  - `aria-label`: なし。

## E2E 固定 selector

| 対象 | `data-testid` | 関連テスト |
| --- | --- | --- |
| 主要ページカード内の開く操作 | `dashboard-primary-page-open-button` | `E2E-UC-001` |
| モバイル表示の主要ページ切り替え操作 | `dashboard-mobile-navigation-toggle` | `E2E-UC-002` |
| グローバルナビゲーション項目 | `dashboard-global-navigation-item` | `E2E-UC-002`, `E2E-UC-026` |
