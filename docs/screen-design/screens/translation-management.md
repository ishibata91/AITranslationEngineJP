# 画面設計: 翻訳管理シェル

- 目的: 未完了ジョブ一覧、新規翻訳の開始、対象ジョブの現在段階への再開を、翻訳管理内の共通シェルで扱う。

## ワイヤーフレーム

```text
+------------------------------------------------+
| [1]                                            |
+------------------------------------------------+
| [2]                                            |
| +--------------------------------------------+ |
| | [3]                                        | |
| | +----------+ +----------+ +----------+     | |
| | | [4]      | | [4]      | | [4]      | ... | |
| | +----------+ +----------+ +----------+     | |
| +--------------------------------------------+ |
| +--------------------------------------------+ |
| | [5]                                        | |
| +--------------------------------------------+ |
+------------------------------------------------+
```

## エレメント

### [1] 翻訳管理ヘッダー

- 概要: 現在の主要ページが翻訳管理であることを示す見出し領域。
- 表示内容: `現在のページ`、`翻訳管理`、翻訳管理の説明文を表示する。
- 依存情報:
  - 表示条件: 現在の主要ページが翻訳管理である。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `translation-management-translation-management-header`
  - `aria-label`: なし。

### [2] 翻訳管理シェル

- 概要: 翻訳管理内の段階表示と下位画面表示領域を縦に並べる領域。
- 表示内容: 段階表示、現在選択されている下位画面を表示する。
- 依存情報:
  - 表示条件: 現在の主要ページが翻訳管理である。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `translation-management-translation-management-shell`
  - `aria-label`: なし。

### [3] 翻訳管理の段階表示

- 概要: 翻訳管理で進む作業の順番と現在位置を示す領域。
- 表示内容: `翻訳管理`、`ジョブの進み方`、各段階の一覧を表示する。
- 依存情報:
  - 表示条件: 翻訳管理シェルが表示されている。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `translation-management-translation-management-stepper`
  - `aria-label`: `翻訳管理の進行状況`

### [4] 段階カード

- 概要: 翻訳管理内の 1 段階を示すカード。
- 表示内容: 段階番号、状態文言、段階名、説明文を表示する。
- 依存情報:
  - 表示条件: 段階定義が存在する。
  - 有効条件: `未完了のジョブ` は直接開ける段階である。
  - 無効条件: `未完了のジョブ` 以外は順番に進む参照表示であり、直接操作できない。
- 操作: 直接開ける段階カードを選択する。
- 結果: 翻訳管理の下位画面表示領域に、選択した下位画面を表示する。
- セレクタ属性:
  - `data-testid`: `translation-management-phase-card`
  - `aria-label`: 状態文言、段階名、説明文を連結した説明。

### [5] 下位画面表示領域

- 概要: 翻訳管理内で選択中または再開中の下位画面を表示する領域。
- 表示内容: 未完了ジョブ一覧、入力データ確認、翻訳設定、選択ジョブの翻訳実行画面のいずれかを表示する。
- 依存情報:
  - 表示条件: 翻訳管理シェルが表示されている。
  - 有効条件: 表示中の下位画面の条件に従う。
  - 無効条件: 表示中の下位画面の条件に従う。
- 操作: 表示中の下位画面で定義された操作を行う。
- 結果: 表示中の下位画面の操作結果に従い、必要に応じて次の下位画面へ切り替わる。
- セレクタ属性:
  - `data-testid`: `translation-management-child-screen-region`
  - `aria-label`: なし。
