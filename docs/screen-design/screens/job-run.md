# 画面設計: 翻訳実行シェル

- 目的: 未完了ジョブ一覧で選んだジョブを対象に、現在の翻訳段階、段階画面の表示領域、次の作業への遷移をまとめて扱う。

## ワイヤーフレーム

```text
+------------------------------------------------+
| [1]                                            |
+------------------------------------------------+
| [2]                                            |
| +--------------------------------------------+ |
| | [3]                                        | |
| +--------------------------------------------+ |
| +--------------------------------------------+ |
| | [4]                                        | |
| | +------------------+ +-------------------+ | |
| | | 進行状況         | | AI 設定           | | |
| | +------------------+ +-------------------+ | |
| | +----------------------------------------+ | |
| | | [7]                                    | | |
| | +----------------------------------------+ | |
| +--------------------------------------------+ |
| +--------------------------------------------+ |
| | [6]                                        | |
| +--------------------------------------------+ |
+------------------------------------------------+
| [5]                                            |
+------------------------------------------------+
```

## エレメント

### [1] 翻訳管理内の段階表示

- 概要: 翻訳管理の作業順と、選択ジョブが表示している現在段階を示す領域。
- 表示内容: 翻訳管理の各段階、現在の段階、段階名、段階の説明を表示する。
- 依存情報:
  - 表示条件: 現在の主要ページが翻訳管理である。
  - 有効条件: 未完了ジョブ一覧へ戻る段階だけを直接選択できる。
  - 無効条件: 単語翻訳、NPC ペルソナ生成、本文翻訳、翻訳完了は、選択ジョブの進行に従って表示されるため直接選択できない。
- 操作: 未完了ジョブ一覧へ戻る段階を選択する。
- 結果: 選択ジョブを解除し、未完了ジョブ一覧を表示する。
- セレクタ属性:
  - `data-testid`: `job-run-translation-management-stepper`
  - `aria-label`: `翻訳管理の進行状況`

### [2] ジョブ実行シェル

- 概要: 選択ジョブ概要、現在段階の画面、次の作業フッター、ジョブ未選択時の案内を持つ領域。
- 表示内容: 選択ジョブがある場合は、選択ジョブ概要、現在段階の画面、次の作業フッターをこの順序で表示する。選択ジョブがない場合は、ジョブ未選択案内を表示する。
- 依存情報:
  - 表示条件: 翻訳管理内で選択ジョブの実行画面が開かれている。
  - 有効条件: 選択ジョブがある場合、現在段階に対応する表示領域と次の作業フッターを表示できる。
  - 無効条件: 選択ジョブがない場合、段階画面と次の作業フッターは表示しない。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `job-run-job-run-shell`
  - `aria-label`: なし。

### [3] 選択ジョブ概要

- 概要: 現在開いているジョブと、ジョブ内の段階順序を最小情報で示す領域。
- 表示内容: `ジョブ #<id>`、`単語`、`NPC`、`本文`、`確認` の段階順序を表示する。段階順序は細い丸とバーで進行位置を表示し、現在段階を強調する。
- 依存情報:
  - 表示条件: 選択ジョブがある。
  - 有効条件: ジョブ ID、現在段階、段階順序を表示できる。
  - 無効条件: 選択ジョブがない場合は表示しない。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: `job-run-selected-job-summary`
  - `aria-label`: なし。

### [4] 段階画面表示領域

- 概要: 選択ジョブの現在段階に対応する段階画面を表示する領域。
- 表示内容: 単語翻訳、NPC ペルソナ生成、本文翻訳、翻訳完了確認のいずれかを表示する。単語翻訳、NPC ペルソナ生成、本文翻訳では、進行状況と AI 設定を横並びで表示し、その下に処理対象一覧を 1 つ表示する。翻訳完了確認では、翻訳完了確認画面の処理対象一覧を表示する。処理対象一覧は、検索、件数、ページ操作、一覧をまとめた共通ラッパーで表示する。
- 依存情報:
  - 表示条件: 選択ジョブがある。
  - 有効条件: 表示中の段階画面の条件に従う。
  - 無効条件: 選択ジョブがない場合は表示しない。本文翻訳の画面状態がない場合、本文翻訳と翻訳完了確認は表示しない。
- 操作: 表示中の段階画面で定義された操作を行う。翻訳完了確認では、翻訳結果のページを移動する。
- 結果: 表示中の段階画面の操作結果に従う。翻訳完了確認では、表示する原文と訳文の範囲が変わる。
- セレクタ属性:
  - `data-testid`: `job-run-phase-screen-region`
  - `aria-label`: 翻訳完了確認のページングは `翻訳結果ページング`。

### [7] 処理対象一覧

- 概要: 選択ジョブの現在段階で処理、生成、確認する実体を確認する領域。
- 表示内容: `処理対象`、現在段階名、処理対象名、処理対象詳細、検索欄、件数、ページ操作、処理対象一覧を表示する。長い処理対象名の全文は浮動ツールチップで表示する。処理対象の詳細は行の下へ開く metadata のアコーディオンで表示し、metadata の先頭項目は連続した情報として表示する。
- 依存情報:
  - 表示条件: 選択ジョブがある。
  - 有効条件: 現在段階で処理、生成、確認する実体を表示できる。
  - 無効条件: 選択ジョブがない場合は表示しない。
- 操作: 検索語を入力する。`前へ` または `次へ` を押す。処理対象行を開く。
- 結果: 検索語に一致する処理対象を表示する。表示する処理対象の範囲が切り替わる。処理対象行の metadata を表示する。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: `処理対象一覧`

### [5] 次の作業フッター

- 概要: 現在段階から未完了一覧、次の翻訳段階、翻訳完了確認、出力管理へ進む固定フッター。
- 表示内容: 次の作業の見出し、次へ進める条件の説明、確認が必要な理由、`未完了一覧へ戻る`、主要操作ボタンを表示する。
- 依存情報:
  - 表示条件: 選択ジョブがある。
  - 有効条件: 単語翻訳では、単語翻訳が完了し、辞書を参照できる場合に次へ進める。NPC ペルソナ生成では、生成結果を参照できる場合に次へ進める。本文翻訳では、本文翻訳が完了し、翻訳結果を確認できる場合に完了確認へ進める。翻訳完了確認では、出力管理へ進める。
  - 無効条件: 次へ進める条件を満たさない場合、主要操作ボタンは無効になり、確認が必要な理由を表示する。
- 操作: `未完了一覧へ戻る` を押す。`次へ進む` を押す。翻訳完了確認では `出力管理へ進む` を押す。
- 結果: `未完了一覧へ戻る` を押すと、選択ジョブを解除し、未完了ジョブ一覧を表示する。`次へ進む` を押すと、次の段階画面へ切り替わる。`出力管理へ進む` を押すと、出力管理を表示する。
- セレクタ属性:
  - `data-testid`: `job-run-next-action-footer`
  - `aria-label`: 見出しと説明を連結した文言。

### [6] ジョブ未選択案内

- 概要: 選択ジョブがない状態で、未完了ジョブ一覧へ戻るよう案内する領域。
- 表示内容: `ジョブ未選択`、`未完了ジョブ一覧でジョブを選んでください`、ジョブIDの手入力を扱わない説明、`一覧へ戻る` を表示する。
- 依存情報:
  - 表示条件: 選択ジョブがない。
  - 有効条件: `一覧へ戻る` は常に操作できる。
  - 無効条件: 選択ジョブがある場合は表示しない。
- 操作: `一覧へ戻る` を押す。
- 結果: 未完了ジョブ一覧を表示する。
- セレクタ属性:
  - `data-testid`: `job-run-job-unselected-guidance`
  - `aria-label`: なし。
