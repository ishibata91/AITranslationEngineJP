- 概要: NPC ペルソナ生成段階と本文翻訳開始に関する操作を並べる領域。
- 表示内容: `翻訳段階の操作`、`操作`、`NPC ペルソナ生成`、`開始`、`中断`、`再開`、`リトライ`、`キャンセル`、`本文翻訳の開始可否を確認`、`本文翻訳を開始`、`更新`、操作できない理由を表示する。
- 依存情報:
