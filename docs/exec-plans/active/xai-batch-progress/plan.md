# Task Plan: xai-batch-progress

`plan.md` は branch 情報と、この task でやること・やらないことの要点を持つ。
設計判断、判断履歴、検証結果、実装結果は持たない。設計は `design.md`、恒久的に残す判断は `docs/changelog.md` に書く。

## やること

- xAI batch 翻訳の進行状況を画面で見えるようにする。今どの段か（固有名 / 本文 / 完了）と、現段 batch の件数（成功 / 処理待ち / 失敗）を進行状況パネルへ出す。
- 操作を 2 つに分ける。「状態確認」は xAI に問い合わせて進行状況を最新化するだけ（取り込み・送信の副作用を持たない）。「取り込み」は完了段を dest へ取り込み、次段 batch を送る。
- ボタン名を「反映」から「取り込み」に変える。「取り込み」は取り込める時（完了段がある時）だけ有効にし、取り込めない時はグレーアウトする。
- backend に、副作用なしで進行状況を返す状態取得の公開面を足す。

## やらないこと

- 翻訳ロジック・provider・batch の永続構造（テーブル定義）は変えない。状態取得は既存の進行行と PollBatch から組む。
- 常駐プロセス・バックグラウンドポーリングは作らない（状態確認は画面操作の時点だけ）。接続情報は永続化しない。
- 実 xAI batch API への課金する自動テストは持たない。実疎通は手動 e2e で確かめる。
