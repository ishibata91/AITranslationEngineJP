# 組み合わせ別few-shot完成訳 v3

## prompt構成

- 現行`role-speech`の1例はpromptから外す
- 次のF1、F2、F3だけを追加例として置く
- 追加3例の直後へ、次の禁止文を置く

`例は語句を写す型ではない。同じ自称、終助詞、命令形を一つの台詞で反復せず、性別や年齢を示すためだけに「来い」「ぞ」「おらん」「おくれ」を選ばない。`

| --- | --- |
| F1 | `I promised to return these books before sunset. Hold the door while I carry them inside.` |
| F2 | `Did you notice footsteps upstairs? Stay beside the wall until the hall is quiet.` |
| F3 | `Leave the heavy box with him. Bring the sealed letter to me; I know where it must go.` |

## 完成訳の規則

- 意味、発話の働き、条件、時間関係、行為者、対象を変えない
- 複数文は全角空白で区切り、訳文末へ句点を置かない
- 原文にない感嘆符、疑問符、罵倒、懇願、事情を足さない
- 性別と年齢は一人称だけに依存せず、3例全体の語彙、接続、指示の形、文の運びで表す
- 幼児語、作り物めいた老人語、固定的な女性語または男性語の反復に依存しない
- KhajiitはF1とF3で三人称自称を使い、F2では種族表現を足さない
