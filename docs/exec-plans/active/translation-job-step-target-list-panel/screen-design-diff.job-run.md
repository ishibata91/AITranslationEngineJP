## 画面差分

### [2] ジョブ実行シェル

- `変更種別`: 変更

概要:
選択ジョブ概要、処理対象一覧、段階画面の表示領域、ジョブ未選択時の案内を持つ領域にする。

表示内容:
- 選択ジョブがある場合は、選択ジョブ概要、処理対象一覧、現在段階の画面をこの順序で表示する。
- 選択ジョブがある場合は、次の作業フッターを現在段階の下に表示する。
- 選択ジョブがない場合は、ジョブ未選択案内を表示する。

### [7] 処理対象一覧

- `変更種別`: 追加

概要:
選択ジョブの現在段階で処理、生成、確認する実体を確認する領域。

配置:
選択ジョブ概要の下、段階画面表示領域の上に配置する。

表示内容:
- `処理対象`
- 現在段階名
- 処理対象名: 処理対象を短く表す実体名
- 処理対象詳細: その実体が現在段階でどう処理、生成、確認されるかを表す利用者向け情報
- 処理対象ページング: 50 件程度を現在ページの表示範囲として扱う。
- ページ操作: `前へ`、`次へ`、現在ページの位置を表示する。

依存情報:
- 表示条件: 選択ジョブがある。
- 有効条件: 現在段階で処理、生成、確認する実体を表示できる。
- データ種別: 表示用の処理対象情報、ページング状態。
- 画面非機能要件: 数万件レベルの処理対象でも、画面要素は現在ページの表示範囲に限定し、ページ切替操作を維持する。

操作:
- `前へ` を押す。
- `次へ` を押す。

結果:
- 表示する処理対象の範囲が切り替わる。

セレクタ属性:
- `aria-label`: `処理対象一覧`

依存部品:
- `ProcessingTargetListPanel`: 各段階で同じ構造の処理対象一覧を表示する。
