# Design: skip-already-japanese-translation

---
## R-1 既に日本語になっている文章を翻訳対象にしない

### 現況の理解

抽出器は英語として解決した原文だけを翻訳対象の原文として保存する。取込は翻訳対象の原文を分類して保存する。翻訳処理は未訳状態の保存内容を翻訳対象として取得する。本文が既に日本語であることを判定する共通処理はない。根拠は REF-1、REF-2、REF-3、REF-4、REF-5 である。

要求が扱う対象の単位と、受け皿が持つキーを並べる。

| | 単位 |
| --- | --- |
| 要求が扱う対象 | 翻訳対象の原文 |
| 受け皿が持つキー | plugin、record、field、ordinal、source |

### あるべき形

取込は、翻訳対象の原文にひらがな、カタカナ、漢字のいずれかが含まれる場合に、原文を訳文として翻訳済みで保存する。同期翻訳とバッチ翻訳は、保存済みの未訳状態にも同じ条件を適用する。同期翻訳とバッチ翻訳は、条件に当てはまる保存済みの翻訳対象の原文を原文と同じ訳文で翻訳済みとして保存し、外部の翻訳処理へ渡さない。
