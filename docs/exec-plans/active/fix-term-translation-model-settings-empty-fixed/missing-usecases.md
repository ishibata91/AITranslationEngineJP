# 不足UC

## 概要

- 対象: 単語翻訳画面（`docs/screen-design/screens/term-translation-phase.md`）に対応するユースケース `翻訳段階を開始する`（`docs/usecases/uc-translation-management.md` 330-381 行）。
- 判断: 差分なし。
- 根拠: 本不具合の確定原因（presenter 層の空文字フォールバック未対応）は実装欠落であり、ユースケースの記述は既存 E1「開始条件が不足する」（365-368 行）で覆える。画面設計の「AI 設定不足: 認証不足またはモデル未選択の警告を表示する」（107-113 行）と組み合わせて、モデル未選択時に開始操作を拒否し理由を表示する経路が説明できる。新規判断必要な仕様変更/機能追加はない。

## 補足

- 採用する修正方針は presenter 層の空文字正規化（`?.trim() || "-"`）であり、UC の経路、条件、例外シナリオの構造は変えない。
- 「runtime snapshot 不在時に AI 設定を未設定として扱う」「ユーザーが設定して固定する経路を確保する」は画面設計の状態別表示（111-112 行）と既存 E1 再実行条件（368 行）の組合せで説明できる。
