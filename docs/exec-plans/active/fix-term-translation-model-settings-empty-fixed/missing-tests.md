# 不足テスト

## 概要

- 対象: 単語翻訳画面の AI モデル設定状態に関する E2E テスト観点。E2E テスト観点正本（`docs/e2e-test-design/test-design.csv`）の関連行は E2E-UC-045（正常: 開始）と E2E-UC-051、E2E-UC-052（処理対象表示の回帰）。
- 判断: 追加候補あり。
- 根拠: 既存 E2E-UC-045 は「AI 設定準備済み」前提の正常系のみで、`runtime snapshot` 不在の未実行ジョブにおける「AI 設定不足: モデル未選択」状態の表示と開始操作拒否を確認する観点が存在しない。修正方針（presenter の空文字正規化）の効果は、未実行ジョブで AI 設定パネルが「設定未完了」を表示し、開始操作がモデル未選択の禁止理由を返す観点で証明する必要がある。

## 補足

- 対象画面（単語翻訳画面）には現状 `data-testid` で固定された AI モデル設定パネルの状態 pill / 開始ボタン禁止理由領域 / select の selector が未固定の箇所がある。`data-testid-gaps.md` に未固定 selector を分けて記録した。
- 既存 E2E-UC-045 は正常系で AI 設定準備済み前提のため、本 task では変更しない。新規 3 観点はその対偶（例外/正常移行）を埋める追加分である。
