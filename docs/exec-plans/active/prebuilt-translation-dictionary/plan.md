# Task Plan: prebuilt-translation-dictionary

## branch情報

- `execution_branch`: `codex/prebuilt-translation-dictionary`
- `target_branch`: `master`
- `source_commit`: `5e971fcc9ffda72a69b4e52737af94fc6d2063f1`

## やること

- **R-1 事前作成した辞書成果物を生成する**: repository直下の`dictionary/`で、中心DBの`master_term`にある公式strings由来の英日対と`category`を移植し、翻訳実行より前に再生成できる辞書成果物を作る。pluginごとの既訳またはAI仮訳を持つ`proper_noun`は移植しない。
- **R-2 MCPから移植した辞書を操作できるようにする**: Codexが移植した辞書項目の検索、取得、追加、修正を頻繁に行える最小のMCPの道具を用意する。原語、訳語、`category`の通常indexと、英語と日本語の部分一致に使う検索用indexを持たせる。
- **R-3 辞書項目の単位、プロパティ、辞書作成規則を固定する**: 同じ表記でも意味が異なる項目を分けて扱う。`Imperial`では、種族を表す名詞、帝国に属することを表す形容詞、帝国軍を表す名詞を別の意味として判定できる形にする。少なくとも原語、訳語、品詞、意味を区別する説明、Skyrimの分類、出どころ、一般辞書との一致状態、レビュー状態、変更理由を持たせる必要があるかを実データで確認する。一般辞書に同じ表記があるかではなく、同じ意味と訳があるかを除外条件にする。既に使用した一般語フィルタで判定できる範囲を先に確認し、不足が判明した場合だけ別の一般英日辞書を入手する。
- **R-4 移植済みの辞書項目を分類して一般語を除外する**: `master_term`由来の17,346件をR-3の規則で分類する。一般辞書に同じ意味と訳がある項目は収録対象外にする。自動判定だけで削除せず、判定結果と理由を保存する。分類、一般語判定、対象件数の確認に必要な操作をMCPへ追加する。
- **R-5 ベースゲームの原文から未収録候補を抽出する**: 公式stringsから得た会話、書籍、その他の英語原文を対象にする。一般辞書と作成中の辞書の両方に同じ意味がない語句を候補として抽出する。形態素解析で候補範囲を狭め、文脈を使う必要がある意味の分類はAIへ渡す。第三者Modのデータは入力に使わない。候補、原文上の出どころ、抽出理由を保存し、候補操作をMCPへ追加する。
- **R-6 AIレビューを行う**: 候補の英語表記、訳語、品詞、意味、Skyrimの分類、一般辞書との重複、出どころを確認する。採用候補、除外候補、人間の判断が必要な候補を分け、判断理由を保存する。同じ候補を再確認できる操作をMCPへ追加する。
- **R-7 人間レビューで辞書項目を確定する**: AIレビュー結果を人間が検索、修正、採用、除外できるようにする。誰がどの値を変更したかと変更理由を残す。人間が採用した項目だけを確定した辞書の出力対象にする。

## 進捗

- R-1: 実装済み。中心 DB の `master_term` 17,346 件から新規辞書成果物を生成し、意味候補と出どころが各17,346件、英語表記と英語表記の検索用indexが各15,917件になることを確認した。生成先に `proper_noun` table は存在しない。
- R-2: 実装済み。R-3のtable分割に合わせてMCPを更新した。R-4では検索、意味の取得と更新、使用箇所の割り当て、一般辞書候補の取得と判定、レビュー、分類実行、変更履歴、件数確認の11操作を公開する。MCP接続と11操作の呼び出しを自動テストで確認した。
- R-3: 規則を`r3-dictionary-rules.md`へ固定した。英語表記、意味、Skyrimでの使用箇所、一般辞書との照合、レビュー、変更履歴を別tableにした。stopwords-isoの一致は10件、日本語WordNet 1.1の英語見出し一致は853件、同じ`synset`で訳語も一致する項目は400件だった。400件のうち145件は複数の`synset`に一致するため、自動照合は除外候補の作成までに制限する。
- R-4: 分類と検分を完了した。17,346件の一般辞書照合を行い、同じ意味の候補がある400件をMCPで検分した。303件を同じ意味と訳として収録対象外にし、97件を人間確認が必要な項目にした。自動判定だけで収録対象外にした項目はない。検分済みDBを正規のpathへ切り替え、新しいMCPの11操作、対象件数、未検分0件を確認した。結果と確認方法は`r4-classification-results.md`に記録した。
