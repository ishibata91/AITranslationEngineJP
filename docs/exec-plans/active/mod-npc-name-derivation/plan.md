# Task Plan: mod-npc-name-derivation

`plan.md` は branch 情報と、人間が見た事象、そこから起こした要求を持つ。
設計は `design.md`、確定仕様は `spec.md`、観測と原因は `investigation.md`、恒久的に残す判断は `docs/changelog.md` が持つ。

## 事象

mod（`inigo.esp`）を翻訳した実行で人間が見た 4 件。当初依頼は 2 件目だが、調査で同じ根を持つ 1 件目が見つかり、3 件目・4 件目の観測が加わった。

- `Sleeping Giant Inn` のような、公式の日本語訳が存在する場所名が英語のまま残る。
- mod が追加した NPC について、氏名が丸ごと本文に出たときは訳語へ置き換わるが、名だけ、苗字だけで出たときは英語のまま残る。
- 台詞の訳文に句読点が入らず、日本語として不自然になる。
- 訳文で話者の男女の区別がつかない。

## 要求

`design.md` と `spec.md` は、ここに書いた番号ごとに節を分ける。

- **R-1 Data フォルダ全体の英日対を既訳の辞書にする**: 日本語 Strings を持たない plugin を訳す実行でも、同じ Data フォルダにある他の plugin の英日対から既訳を集め、辞書として使う。
- **R-2 実行内で確定した NPC 名から部分形の訳を作る**: 実行内で訳が確定した NPC の氏名から、名だけ・苗字だけの形の訳を作り、本文の機械置換へ載せる。
- **R-3 台詞の口調指示から句点の禁止を外す**: 台詞の訳文の句点の有無を翻訳モデルが本文から判断できるように、口調指示から句点を禁じる指定を外す。
- **R-4 話者の性別を口調指示の行として出す**: 役割語テンプレートを引くキーとしてだけ使っている話者の性別を、翻訳プロンプトの口調指示に行として載せる。

## やらないこと

- 既訳流用（原文が参照訳と完全一致する叙述文・台詞へ AI を呼ばず既訳を確定訳にする経路）で機械置換が効かない件。本 task の 4 件とは別の観測事象として扱う。
- 一般名詞を含む固有名が本文へ部分一致して原文を壊す件そのものへの新しい防御。公式訳の供給が戻れば、より長い固有名が最長一致で優先されて主な破壊は解消する見込みのため、供給を直した後の実測で残るかを判断する。
- 走査結果を再利用して 2 回目以降の走査を省く仕組み。全件走査の実測が 18 秒で、翻訳本体に対して無視できるため入れない。
- 叙述文・台詞の訳文品質そのものの改善。
