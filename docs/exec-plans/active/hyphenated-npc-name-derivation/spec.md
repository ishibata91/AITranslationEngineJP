# Spec: hyphenated-npc-name-derivation

---

## R-1 ハイフンを含む NPC 氏名の部分形を本文の参考語へ加える

- R-1-1（正常系）: 事前作成辞書または翻訳対象 mod の `NPC_` 氏名が `Hoge Black-Briar` と `ホゲ・ブラック・ブライア` の形で安全規則を通る時、本文に出た `Hoge` と `Black-Briar` の訳を本文の参考語へ加えること。
    - 前提条件: `Hoge` と `Black-Briar` が本文に出る。
    - 確かめ方: 同期翻訳と batch 翻訳で送る本文の参考語に、`Hoge → ホゲ` と `Black-Briar → ブラック・ブライア` が出る。
    - 対応する実テスト: REF-7、REF-8、REF-9。
- R-1-2（対象に入る側の境界）: 英語の空白区切り部分に複数のハイフンを含み、その全てと日本語の中黒区切り部分を対応付けられる時、各英語部分の訳を本文の参考語へ加えること。
    - 前提条件: 英語の空白区切り部分と、その中のハイフン区切りの合計数が日本語の中黒区切り数と一致する。
    - 確かめ方: 送る本文の参考語に、各英語部分と対応する日本語部分が出る。
    - 対応する実テスト: REF-7。
- R-1-3（対象に入らない側の境界）: 英語の空白区切り部分と、その中のハイフン区切りの合計数が日本語の中黒区切り数と一致しない時、部分形の訳を本文の参考語へ加えないこと。
    - 前提条件: `Hoge Black-Briar` に対して中黒区切りの日本語が二つまたは四つである。
    - 確かめ方: 送る本文の参考語に、`Hoge` または `Black-Briar` から作る訳が出ない。
    - 対応する実テスト: REF-7。
- R-1-4（対象に入らない側の境界）: 横断辞書を作る既存の人名派生では、ハイフンを含む NPC 氏名から新しい部分形を作らないこと。
    - 前提条件: 横断辞書を作る既存の人名派生に `Hoge Black-Briar` と `ホゲ・ブラック・ブライア` がある。
    - 確かめ方: 横断辞書に `Hoge` または `Black-Briar` から作る新しい訳が出ない。
    - 対応する実テスト: REF-8。
