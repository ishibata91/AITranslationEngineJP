# Task Plan: prebuilt-dictionary-editor

## 要求

- **R-1 プリビルド辞書を編集する**: プリビルド辞書をテーブルUIから作成、閲覧、更新、削除できるようにする。
- **R-2 テーブルUIで絞り込む**: テーブルUIを50件単位でページングし、表示する各カラムでプリビルド辞書をフィルタできるようにする。
- **R-3 編集APIを読み取り経路から分離する**: 編集APIを既存の読み取り経路とは別経路に重複して作り、既存の読み取り経路を変更しないようにする。
- **R-4 行ごとの変更を確定する**: テーブルUIの行を列ごとに編集または削除保留にし，取消または確定までページングを無効化する。確定では変更した項目だけを更新し，削除保留の行だけを削除する。
