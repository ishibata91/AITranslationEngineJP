# Design: prebuilt-dictionary-editor

## R-1 用語辞書を編集する

### 現況の理解

用語辞書は原語、訳語、品詞、Skyrimカテゴリを持つ。用語辞書を開く編集APIと、テーブルUIを表示する画面は存在する。原語は複数の訳語を持てる。Skyrimカテゴリは用語辞書の表示とフィルタに使う。根拠はREF-1、REF-2、REF-10、REF-12、REF-13である。

### あるべき形

テーブルUIは原語、訳語、品詞、Skyrimカテゴリを表示する。複数のSkyrimカテゴリを持つ行は最初に畳み、操作時にカテゴリごとの行を表示する。テーブルUIは原語、訳語、品詞を持つ行を作成、更新、削除する。Skyrimカテゴリは表示とフィルタだけに使う。原語の更新は、編集した行に表示している訳語とSkyrimカテゴリだけを新しい原語へ移す。用語辞書が受け付けない品詞は作成または更新しない。更新と削除は、表示後に内容が変わっていた場合に保存しない。作成は新しい行を保存する。削除は用語辞書にある関連する内容を削除し、変更を残す。

## R-2 テーブルUIで絞り込む

### 現況の理解

既存の検索は検索条件と件数上限を持つ。既存の編集APIはページ番号、総件数、原語、訳語、品詞、Skyrimカテゴリを扱う。テーブルUIは原語、訳語、品詞、Skyrimカテゴリの列と検索操作を持つ。根拠はREF-6、REF-12、REF-13である。

### あるべき形

テーブルUIは原語、訳語、品詞、Skyrimカテゴリの各列に独立したフィルタを持つ。検索は入力済みのフィルタとページ番号を編集APIへ送る。編集APIは常に50件以下の用語とSkyrimカテゴリと総件数を返す。テーブルUIは総件数とページ番号から前後のページを表示する。

## R-3 編集APIを読み取り経路から分離する

### 現況の理解

翻訳の読み取り経路は読み取り専用の用語辞書を使う。編集APIは読み取り経路とは別に用語辞書を開く。アプリケーションの起動と終了は読み取り経路と編集APIを別に管理する。根拠はREF-3、REF-9、REF-10、REF-11である。

### あるべき形

編集APIは翻訳の読み取り経路とは別に、用語辞書の作成、検索、更新、削除を扱う。編集APIは読み取り経路の型、用語辞書を開く方法、検索、翻訳処理を使わない。翻訳の読み取り経路は変更しない。アプリケーションの起動と終了は編集APIを読み取り経路とは別に管理する。

## R-4 行ごとの変更を確定する

### 現況の理解

テーブルUIは原語、訳語、品詞の入力欄、削除操作、Skyrimカテゴリを開く操作を持つ。行は変更時に薄い黄色、削除保留時にグレーで表示する。テーブルUIは検索済みの内容と保留中の変更を別に持つ。根拠はREF-12、REF-13である。

### あるべき形

テーブルUIは行の原語、訳語、品詞ごとに変更前と変更後を持つ。削除操作は削除保留を表示し、削除保留の行とSkyrimカテゴリをグレーで表示する。テーブルUIは変更した行と削除保留の行を保持する。変更がある間はページングと検索を無効化し、全て取消と変更を確定を表示する。全て取消は全ての保留を捨て、各行を変更前へ戻す。変更を確定は削除保留の行だけを削除し、編集した行は変更した原語、訳語、品詞だけを更新する。原語を更新する時は、表示後に内容が変わっていた場合に保存しない。更新後は用語辞書を読み直す。

## R-5 行ごとの保留を取り消す

### 現況の理解

行は作成、編集、削除の保留を持つ。テーブルUIは全ての保留を戻す全て取消を持つ。根拠はREF-12、REF-13である。

### あるべき形

テーブルUIは編集または削除を保留した行に同じ取消を表示する。編集の取消は選んだ行だけを変更前へ戻す。削除の取消は選んだ行の削除保留だけを戻し、編集の保留を残す。新規作成した行の取消は行を表示から除く。行の取消は別の行の編集、削除保留、ページングと検索の無効状態を変えない。全ての保留がなくなった時だけ、ページングと検索を有効にする。変更を確定は取消後に残る保留だけを保存する。

## R-6 編集する行だけを入力欄にする

### 現況の理解

表示コンポーネントは渡された一行だけを入力欄にできる。画面は入力欄にする行と編集操作を持たないため、実際の用語辞書では行を入力欄にできない。50件表示の全行を入力欄にするとGPU使用率が高くなり、文字表示にすると軽くなることを利用者が確認した。根拠はREF-12、REF-13である。

### あるべき形

テーブルUIは一つの編集する行を持つ。通常時は原語、訳語、品詞を文字表示し、編集する行だけを入力欄にする。編集操作は削除保留でない行を編集する行にする。別の行を編集すると前の行は文字表示へ戻し、前の行の保留を残す。新規作成した行は作成直後から入力欄にする。行の取消、全て取消、変更を確定後の読み直し、削除保留は編集する行を解除する。編集する行を変えても、保留、ページング、検索の状態は変えない。
