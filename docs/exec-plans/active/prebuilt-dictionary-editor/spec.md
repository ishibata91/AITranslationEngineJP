- R-1-1（正常系）: 利用者がテーブルUIから入力内容を持つプリビルド辞書を作成できること
  - 前提条件: 新しいプリビルド辞書の入力内容が揃っている
  - 確かめ方: テーブルUIで作成後に入力内容を持つプリビルド辞書が表示されることを確認する
  - 対応する実テスト:
- R-1-2（正常系）: 利用者がテーブルUIに表示されたプリビルド辞書の入力内容を確認できること
  - 前提条件: テーブルUIにプリビルド辞書が表示されている
  - 確かめ方: テーブルUIで選択したプリビルド辞書の入力内容を確認する
  - 対応する実テスト:
- R-1-3（正常系）: 利用者がテーブルUIに表示されたプリビルド辞書を更新できること
  - 前提条件: テーブルUIにプリビルド辞書が表示されている
  - 確かめ方: テーブルUIで更新後の入力内容が表示されることを確認する
  - 対応する実テスト:
- R-1-4（正常系）: 利用者がテーブルUIに表示されたプリビルド辞書を削除できること
  - 前提条件: テーブルUIにプリビルド辞書が表示されている
  - 確かめ方: テーブルUIで削除したプリビルド辞書が表示されないことを確認する
  - 対応する実テスト:
- R-1-5（対象に入る側の境界）: 利用者が同じ入力内容の一部を持つ複数のプリビルド辞書を作成できること
  - 前提条件: テーブルUIに表示されているプリビルド辞書と入力内容の一部が同じ新しいプリビルド辞書を作成している
  - 確かめ方: テーブルUIで作成後に複数のプリビルド辞書が表示されることを確認する
  - 対応する実テスト:
- R-1-6（対象に入らない側の境界）: 利用者が必要な入力内容を欠くプリビルド辞書を作成または更新できないこと
  - 前提条件: テーブルUIで必要な入力内容を欠くプリビルド辞書を入力している
  - 確かめ方: テーブルUIに保存されないことを確認する

## R-2 テーブルUIで絞り込む

- R-2-1（正常系）: 利用者がテーブルUIに表示する各カラムでプリビルド辞書をフィルタできること
  - 前提条件: 各カラムに一致するプリビルド辞書と一致しないプリビルド辞書がある
  - 確かめ方: テーブルUIの各カラムにフィルタを入力し，一致するプリビルド辞書だけが表示されることを確認する
  - 対応する実テスト:
- R-2-2（対象に入る側の境界）: 利用者が51件以上のプリビルド辞書をフィルタした場合に50件ごとのページを移動できること
  - 前提条件: フィルタに一致するプリビルド辞書が51件以上ある
  - 確かめ方: テーブルUIで1ページに50件が表示され，次のページに残りのプリビルド辞書が表示されることを確認する
  - 対応する実テスト:
- R-2-3（対象に入らない側の境界）: 利用者がプリビルド辞書に一致しないフィルタを入力した場合にプリビルド辞書が表示されないこと
  - 前提条件: テーブルUIのいずれかのカラムに一致しないフィルタが入力されている
  - 確かめ方: テーブルUIにプリビルド辞書が表示されないことを確認する

## R-3 編集APIを読み取り経路から分離する

- R-3-1（正常系）: 利用者がテーブルUIからプリビルド辞書を編集しても既存の読み取り経路が編集用APIを呼ばないこと
  - 前提条件: テーブルUIでプリビルド辞書を作成，更新，または削除している
  - 確かめ方: 翻訳用APIと読み取り専用ストアの呼び出し記録に編集用APIまたは編集用ストアが現れないことを確認する
  - 対応する実テスト:
- R-3-2（対象に入る側の境界）: 利用者がテーブルUIに表示された内容からプリビルド辞書を更新した場合に保存できること
  - 前提条件: 表示後にプリビルド辞書が更新されていない
  - 確かめ方: テーブルUIで更新後に入力した内容が表示されることを確認する
  - 対応する実テスト:
- R-3-3（対象に入らない側の境界）: 利用者が表示後に更新されたプリビルド辞書を更新した場合に更新できないこと
  - 前提条件: 別の編集によってプリビルド辞書が更新されている
  - 確かめ方: テーブルUIで古い内容が保存されず，更新できないことが表示されることを確認する

  - 確かめ方: 編集した行と取消および確定の操作が表示されることを確認する
  - 対応する実テスト:

  - 確かめ方: 削除対象の行がグレーアウトし，確定前には表示から消えないことを確認する
  - 対応する実テスト:

  - 前提条件: テーブルUIに変更または削除を保留した行がある
