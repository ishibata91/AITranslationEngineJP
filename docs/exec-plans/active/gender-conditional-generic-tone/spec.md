# Spec: gender-conditional-generic-tone

---

## R-1 条件分岐の性別を汎用として扱う

- R-1-1（正常系）: 同一の条件分岐に男性と女性が現れる場合に，男女汎用の口調を使うこと。
    - 前提条件: 同一の INFO に男性条件と女性条件がある。
    - 確かめ方: 抽出済み条件の性別が空であり，台詞条件の性別が空であることを確認する。
    - 対応する実テスト: `condition-sex-both-generic`
- R-1-2（対象に入る側の境界）: 同一の条件分岐に男性だけが現れる場合に，男性の口調を使うこと。
    - 前提条件: 同一の INFO に男性条件があり，女性条件がない。
    - 確かめ方: 抽出済み条件と台詞条件の性別が男性であることを確認する。
    - 対応する実テスト: `condition-sex-male-only`
- R-1-3（対象に入る側の境界）: 同一の条件分岐に女性だけが現れる場合に，女性の口調を使うこと。
    - 前提条件: 同一の INFO に女性条件があり，男性条件がない。
    - 確かめ方: 抽出済み条件と台詞条件の性別が女性であることを確認する。
    - 対応する実テスト: `condition-sex-from-getissex`
- R-1-4（対象に入らない側の境界）: 性別条件が無い場合に，性別による口調を使わないこと。
    - 前提条件: 同一の INFO に男性条件も女性条件もない。
    - 確かめ方: 抽出済み条件と台詞条件の性別が空であることを確認する。
    - 対応する実テスト: `condition-sex-absent`
