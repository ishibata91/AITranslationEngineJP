## やることの要点

### R-1 バッチ実行後は完了まで自動で状態確認する

- OpenAI と xAI の配送方式でバッチ実行を押した後は、対象 plugin の進行状況を自動で取得する。固有名段を含む各チャンクと本文段を人の追加操作なしで完了まで進め、取り込んだ訳文を結果一覧へ表示する。

### R-2 画面を閉じた後は人の操作で既存のバッチ実行を再開する

- 画面を閉じると自動の状態確認を止める。
- 画面を再び開いた後は、バッチ実行を押した時に対象 plugin と provider に対応する保存済みの batch の進行を確認する。途中なら自動の状態確認を再開する。

### R-3 状態確認ボタンを削除する

- OpenAI と xAI の操作から状態確認ボタンを削除する。
- バッチ実行中、完了、停止、失敗、未訳だけの再送信を、進行状況と一つの主操作で判別できるようにする。主操作の開始中と自動の状態確認中は、多重実行できないようにする。

## やらないことの要点

- 画面を閉じた後も動き続ける backend の定期実行は追加しない。
- API キーと endpoint を永続化しない。
- 外部 batch が `failed` になった場合の自動再送信は追加しない。
- 同期実行の操作と進行表示は変更しない。
