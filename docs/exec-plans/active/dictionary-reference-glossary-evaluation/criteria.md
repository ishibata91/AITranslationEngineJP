## 標本

| 用途 | 件数 | 層別の軸 | 使った回数 |
| --- | ---: | --- | ---: |
| 開発用 | 50文 | `proper-term` 13件、`homograph` 3件、`phrase-collision` 1件、`no-candidate` 6件、`category-coverage` 27件 | 4 |
| 評価用 | 100文 | 開発用と同じ5軸。各軸20件 | 0 |

評価用は、開発用で少なかった同綴りと句の衝突を各20件に増やし、候補誤適用を意図的に厳しく測る。カテゴリ層は`NPC_`、`LCTN`、`WEAP`、`ARMO`、`BOOK`、`SPEL`、`SHOU`から抽出した候補を使う。誤訳0件は標本内の全件について確認する。一般化した誤訳率が厳密に0であることまでは証明しない。

正解は各文について、候補ごとの`use`または`ignore`と期待する指定訳を標本作成時に固定する。正解のない文は混ぜない。

## 測る道具

- 場所: `tmp/dictionary-reference-glossary-experiment/measure.mjs`
- 出す内容: 達成条件の値、達成の線、判定、数えた件数、外した件数と理由、指定件数の無作為標本。
- 標本の件数: command引数で指定する。

## 誤りの種類

| 種類 | 何を数えるか |
| --- | --- |
| 意味の変更 | 原文の対象、動作、性質、関係を別の意味へ変えた出力 |
| 情報の欠落 | 原文の対象、場所、動作、否定、数量のいずれかを訳文から失った出力 |
| 情報の追加 | 原文にない対象、カテゴリ説明、事実を加えた出力 |
| 文体の変更 | 命令、質問、会話、叙述の別を変えた出力 |
| 不自然な日本語 | 意味は取れるが、語順、助詞、語の選択が不自然な出力 |
| 指定訳の不採用 | `use`の参考用語について指定された日本語文字列を使わなかった出力 |
