# 参考用語提示のアイデア評価

## 評価1

### 固定するアイデア

翻訳対象の原文を辞書で置換しない。原文に含まれる収録対象の英日対を検索し、各英日対のSkyrimカテゴリ名とカテゴリの日本語説明を添えて、翻訳AIへ参考用語として渡す。

参考用語は強制訳ではない。同じ意味または対象で使われている場合だけ採用するよう指示する。

### 変更前

原文だけを`gpt-5.6-luna`へ渡して日本語へ翻訳する。

### 期待する効果

- 固有名詞、固有の対象名、ゲーム固有語が辞書の訳語と一致する。
- 音写と非直訳の表記揺れが減る。
- 原文の意味、情報、自然な日本語を維持する。

### アイデアが効かないと判断できる差

- 参考用語なしとありで辞書語の訳が変わらない。
- 参考用語ありでも辞書の訳語を採用しない。
- 参考用語による改善より、意味または日本語の悪化が目立つ。

### 予想する副作用

- 一般語と同じ表記のゲーム用語を、原文と異なる意味で採用する。
- 長い固有名を機械的に入れ、文章が不自然になる。
- カテゴリの説明を原文の意味と誤認する。
- 複数の参考用語が翻訳文へ不要に混入する。

### 標本

50件の英語文を使用する。文章は評価用に作成または改変してよい。

| 種類 | 含める対象 |
| --- | --- |
| 効果が現れる対象 | 人物、地名、装備、書籍、呪文、能力、素材などの辞書語を含む文 |
| 効果が現れない対象 | 参考用語がない文、通常の翻訳で十分な文 |
| 副作用が現れやすい対象 | 一般語とゲーム用語が同じ表記で、文脈上は一般的な意味で使う文 |
| 通常範囲 | 会話文、叙述文、表示文を想定した短文 |

標本の実体は`tmp/dictionary-reference-glossary-evaluation/eval-01/samples.jsonl`へ保存する。

### 揃える条件

- モデル: `gpt-5.6-luna`
- API: OpenAI Batch APIの`/v1/chat/completions`
- 推論設定: `reasoning_effort=medium`
- 原文: 変更前と適用後で同一
- 出力形式: IDと日本語訳だけを持つJSON
- 翻訳指示: 参考用語の節以外は同一

### 数え方

| 観点 | 数え方 |
| --- | --- |
| 辞書訳の採用 | 原文と同じ意味で使われる参考用語について、指定訳が出力に現れた件数 |
| 意味の維持 | 原文の対象、動作、否定、数量、関係を保持した件数 |
| 自然さ | 日本語として不自然な語順、助詞、重複がない件数 |
| 誤誘導 | 一般的な意味の語へゲーム固有の参考訳を誤適用した件数 |
| 不要な混入 | 原文にない対象またはカテゴリ説明を訳へ追加した件数 |
| 運用差 | 入力token、出力token、処理時間の差 |

自動集計だけで翻訳品質を決めない。変更前と適用後の出力を読み、意味、文脈、文体、情報欠落を確認する。

### 支持と棄却の境界

採用可能な改善件数と許容できる副作用件数を人間がまだ指定していない。効果と副作用を同じ50件で測り、両方がある場合は`人間判断`として差を提示する。改善がなく副作用だけがある場合は`棄却`、改善があり確認できる副作用がない場合は`支持`とする。

### 評価を終える条件

- 変更前50件と適用後50件の応答が揃う。
- 入力IDと出力IDが一対一で一致する。
- 両条件の出力と利用量を保存する。
- 50組を比較し、効果、副作用、予想外の変化を記録する。

### 実行結果

- Batch ID: `batch_6a70d39e34c48190aa8a7d44fb4d38e9`
- API応答: 変更前50件、適用後50件の全100件が成功した。
- 参考用語: 50件中44件へ合計47語を提示した。
- 指定訳との文字列一致: 変更前12語、適用後44語だった。適用後は32語増えた。
- 入力token: 変更前5,556、適用後10,137だった。
- 合計token: 変更前7,477、適用後12,456だった。適用後は約1.67倍だった。

条件名を伏せた比較では、次の結果になった。意味と自然さは、原文の情報を保って自然な日本語になっているかを50件ごとに判定した。

| 観点 | 変更前 | 適用後 |
| --- | ---: | ---: |
| 意味を維持した件数 | 48 | 37 |
| 自然だった件数 | 48 | 41 |
| 選好された件数 | 21 | 7 |

同等の判定は22件だった。

### 確認できた効果

- `Abacean Longfin`、`Stalhrim Sword`、`Black Book: The Winds of Change`、`Mehrunes' Razor`などは、DBの指定訳と一致した。
- 固有名詞、装備名、書籍名、薬名では、音写、語順、公式訳に相当する表記が安定した。
- カテゴリの日本語説明が、そのまま訳文へ追加された例は確認できなかった。

### 確認できた副作用

- `Old people race to the shelter.`では、部分一致した`Old People Race`を採用し、「古き人の種族は避難所へ急いだ」と誤訳した。
- `imperial measurements`では、一般語の`imperial`へ人物・種族の参考訳「インペリアル」を適用した。
- `Twilight Sepulcher Inner Sanctum`を含む文では、入場先の固有名詞全体を訳文から欠落させた。
- `physician`へ「医薬師」を適用し、一般的な医師という意味を変えた。
- `Moss`を「カサダケ」とした例など、DBに収録された訳自体の意味差も翻訳へ持ち込んだ。
- 参考用語の提示によって、命令文が説明文へ変わる例と、原文の語が欠落する例があった。

### 予想外の変化

指定訳との文字列一致は47語中12語から44語へ増えた。一方、条件を伏せた意味維持の判定は48件から37件へ減った。参考用語を強制訳ではないと明記しても、モデルは一般語への部分一致と意味の異なるDB項目を強く採用した。

### 判定

`人間判断`とする。

参考用語の提示は、固有名詞とゲーム固有語の表記を揃える効果を確認できた。しかし、50件中13件で適用後の意味維持に失敗した。改善を許容できる副作用件数の境界は未指定であり、現状の全一致候補をそのまま提示する方式は採用可能とは判定できない。

次の評価を行う場合は、DBの採否を再判定するのではなく、原文中の語境界と候補の意味が一致する場合だけ参考用語を提示する方法を、今回と同じ50件で比較する必要がある。
