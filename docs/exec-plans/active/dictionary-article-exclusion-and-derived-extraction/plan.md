# Task Plan: dictionary-article-exclusion-and-derived-extraction

このplanは次の実装taskの入口である。
設計と仕様はまだ作成しない。

## 事象

- 事前作成済み辞書の原語には、本文の最長一致で照合すると先頭冠詞が一致条件を不必要に狭める語がある。
- 事前作成済み辞書の原語には、本文に現れる有用な部分語を持つ複合語がある。
- 部分語を無条件に辞書候補へ加えると、一般語への誤一致と複数の由来を持つ候補の混入が起こり得る。

## 要求

- **R-1 冠詞を除外した照合形を追加する**: 事前作成済み辞書の原語について、先頭冠詞を除外した照合形を最長一致候補として扱えるようにする。
- **R-2 辞書単語から限定的な派生照合形を抽出する**: 事前作成済み辞書の一部の複合語から、本文照合に使える派生語を生成して候補へ加える。
- **R-3 誤一致を抑止する**: 冠詞除外形と派生語の追加が一般語、短すぎる語、意味の異なる候補へ誤って一致しない条件を設計で固定する。
- **R-4 参考語化した本文翻訳へ接続する**: 一致した冠詞除外形または派生語は、原語、訳候補、品詞、意味、カテゴリ、由来を本文翻訳の参考語として渡す。
- **R-5 同期翻訳とbatch翻訳を一致させる**: 同期翻訳とbatch翻訳が同じ派生規則、最長一致規則、参考語保存、結果表示を使う。
