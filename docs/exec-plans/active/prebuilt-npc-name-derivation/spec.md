# Spec: prebuilt-npc-name-derivation

---

## R-1 事前作成辞書の NPC から人名の部分形の訳を本文の参考語へ加える

- R-1-1（正常系）: 事前作成辞書に `NPC_` の二つ名または空白で区切られた氏名があり、既存の人名派生規則を通る時、本文に出た人名の部分形の訳を本文の参考語へ加えること。
    - 前提条件: 二つ名の前部または姓名の各語が本文に出て、事前作成辞書の日本語が規則に必要なカタカナの形を持つ。
    - 確かめ方: 同期翻訳と batch 翻訳で送る本文の参考語に、部分形の英語と日本語が出る。
    - 対応する実テスト: REF-10、REF-11。
- R-1-2（対象に入る側の境界）: 同じ英語と日本語が `NPC_` と別の収録情報の両方にある時も、人名の部分形の訳を本文の参考語へ一度だけ加えること。
    - 前提条件: 事前作成辞書に同じ英語と日本語を持つ複数の収録情報があり、その一つに `NPC_` がある。
    - 確かめ方: 送る本文の参考語に、部分形の英語と日本語が一度だけ出る。
    - 対応する実テスト: REF-10。
- R-1-3（対象に入らない側の境界）: `NPC_` を持たない氏名、二つ名でも空白で区切られた姓名でもない氏名、または既存の人名派生規則を通らない氏名から、人名の部分形の訳を本文の参考語へ加えないこと。
    - 前提条件: NPC 以外の氏名、短縮名だけの氏名、または一般語として用法の集計に現れる氏名がある。
    - 確かめ方: 送る本文の参考語に、対象外の氏名から作る部分形の英語と日本語が出ない。
    - 対応する実テスト: REF-10。
- R-1-4（対象に入らない側の境界）: 事前作成辞書の完全形または翻訳する plugin の翻訳済み固有名が同じ英語を持つ時、別の訳の人名の部分形を本文の参考語へ加えないこと。
    - 前提条件: 人名の部分形と同じ英語を、完全形または翻訳済み固有名が持つ。
    - 確かめ方: 送る本文の参考語に、その英語の派生した日本語が出ない。
    - 対応する実テスト: REF-10。
- R-1-5（対象に入らない側の境界）: 翻訳する plugin 以外の会話文が、人名の部分形の訳を本文の参考語へ加えるかどうかを変えないこと。
    - 前提条件: 翻訳する plugin の会話文にある氏名について、別の plugin の会話文だけに同じ英語の小文字の用法がある。
    - 確かめ方: 別の plugin の会話文の有無で、送る本文の参考語に部分形の英語と日本語が出るかどうかが変わらない。
    - 対応する実テスト: REF-10。
- R-1-6（対象に入らない側の境界）: 人名の部分形の訳を本文の参考語へ加えても、事前作成辞書、横断辞書、翻訳する plugin の固有名を変更しないこと。
    - 前提条件: 事前作成辞書の NPC から人名の部分形の訳を作れる。
    - 確かめ方: 本文の参考語を作る前後で、事前作成辞書、横断辞書、翻訳する plugin の固有名の件数と内容が変わらない。
    - 対応する実テスト: REF-10。
- R-1-7（対象に入らない側の境界）: 翻訳する plugin の短縮名が人名の部分形と同じ英語を持つ時、人名の部分形の訳を本文の参考語へ加えないこと。
    - 前提条件: 翻訳する plugin の短縮名と、事前作成辞書の NPC から作れる人名の部分形が同じ英語を持ち、日本語が異なる。
    - 確かめ方: 送る本文の参考語に短縮名の英語と日本語だけが出て、人名の部分形の英語と日本語が出ない。
    - 対応する実テスト: REF-10。
