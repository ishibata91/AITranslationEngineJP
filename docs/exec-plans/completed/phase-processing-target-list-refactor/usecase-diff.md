# UC差分: phase-processing-target-list-refactor

## 目的

処理対象一覧の件数一致、一覧表示、検索を、翻訳管理の現在段階で確認する UC 差分として固定する。
この文書は task-local の UC 差分であり、docs 正本文は `docs正本化判断` 後に `docs_updater` が扱う。

## 対象 UC

- 正本候補: `docs/usecases/uc-translation-management.md`
- 対象セクション: `ユースケース: 処理対象を確認する`
- 関連フェーズ: 単語翻訳、NPC ペルソナ生成、本文翻訳

## 追加する意図

- Skyrim Mod 翻訳者は、現在段階の処理対象一覧を確認できる。
- Skyrim Mod 翻訳者は、進行状況の処理対象件数と一覧件数が同じ母集団を指すことを判断できる。
- Skyrim Mod 翻訳者は、処理対象一覧を検索できる。

## 主シナリオ差分

既存の主シナリオに次を追加する。

1. システムが、現在段階の処理対象件数と一覧 total を同じ母集団から表示する。
2. システムが、処理対象一覧の行を表示する。
3. Skyrim Mod 翻訳者が、検索語を入力する。
4. システムが、現在段階の検索対象に一致する処理対象だけを表示する。
5. システムが、検索後の一覧件数を表示する。

## フェーズ別の母集団

| フェーズ | 処理対象一覧の母集団 | 検索対象 |
| --- | --- | --- |
| 単語翻訳 | 共通辞書対象外の用語と固有名詞。画面上の処理対象件数は AI 翻訳対象語件数と矛盾しない。 | 処理対象名、原文相当、訳語候補相当 |
| NPC ペルソナ生成 | 現行の NPC ペルソナ生成対象。 | 名前、FormID、EditorID、NPC 属性 |
| 本文翻訳 | 辞書置換対象外の翻訳項目。画面上の処理対象件数は AI 送信対象件数と矛盾しない。 | 名前、原文、訳語 |

## 代替シナリオ差分

### A1. 検索結果がない

- 発生条件: 検索語に一致する処理対象がない。
- 流れ:
  1. システムが、検索後の一覧件数を 0 件として表示する。
  2. システムが、処理対象がないことを表示する。
  3. システムが、現在段階の進行状況を変更しない。
- 結果: Skyrim Mod 翻訳者は、検索条件に一致する処理対象がないことを確認できる。

## 完了条件差分

- 成功条件: 3 フェーズすべてで、処理対象一覧または検索結果 0 件の空状態を確認できる。
- 成功条件: 3 フェーズすべてで、一覧 total と画面上の処理対象件数が同じ母集団を指す。
- 成功条件: 3 フェーズすべてで、検索語により処理対象一覧を絞り込める。
- 不変条件: 処理対象一覧の検索は、翻訳結果、段階状態、進行状況を変更しない。
