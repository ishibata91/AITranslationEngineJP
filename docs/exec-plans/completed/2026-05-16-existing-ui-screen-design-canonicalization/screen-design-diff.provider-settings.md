# 画面設計: AIサービス設定

- 目的: AIサービスごとのエンドポイント、APIキー状態、接続確認状態を確認し、選択した AIサービスの設定を保存またはリセットする。

| | +------------+ | | +---------------------+ | |

## エレメント

### [1] 画面シェル

- 概要: AIサービス設定画面全体を表示する領域。
- 表示内容: 画面概要領域、AIサービス一覧、選択中 AIサービスの設定詳細を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [2] 画面概要領域

- 概要: 画面の目的、処理状態、接続状態、通知を表示する領域。
- 表示内容: `中央設定`、`AIサービス設定`、処理状態、`Gateway: 接続準備済み` または `Gateway: 未接続`、画面説明、管理対象件数、保存通知、エラーメッセージを表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [3] AIサービス一覧領域

- 概要: 設定対象の AIサービスを比較して選択する領域。
- 表示内容: `AIサービス一覧`、`設定状態を比較`、AIサービス行の一覧を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [4] 設定詳細領域

- 概要: 選択中 AIサービスの設定内容を表示し、編集操作をまとめる領域。
- 表示内容: `設定詳細`、選択中 AIサービス名、接続確認状態、エンドポイント入力、APIキー状態、接続確認、設定操作を表示する。
- 依存情報:
  - 表示条件: 選択中 AIサービスがある。
  - 有効条件: なし。
  - 無効条件: 選択中 AIサービスがない場合は表示しない。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [5] AIサービス行

- 概要: AIサービスを選択する一覧行。
- 表示内容: AIサービス名、設定状態、状態の補足説明を表示する。AIサービス名は `Gemini`、`xAI`、`LM Studio` を表示する。
- 依存情報:
  - 表示条件: AIサービスが 1 件以上ある。
  - 有効条件: 常に選択できる。
  - 無効条件: なし。
- 操作: AIサービス行を選択する。
- 結果: 選択した AIサービスの設定詳細を表示する。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [6] エンドポイント入力

- 概要: 選択中 AIサービスの接続先を入力する領域。
- 表示内容: `エンドポイント`、入力欄、接続先の補足説明を表示する。`LM Studio` では `http://127.0.0.1:1234/v1` を入力例として表示し、その他の AIサービスでは `https://` を入力例として表示する。
- 依存情報:
  - 表示条件: 選択中 AIサービスがある。
  - 有効条件: 常に入力できる。
  - 無効条件: なし。
- 操作: エンドポイントを入力する。
- 結果: 選択中 AIサービスの保存待ち設定が更新される。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [7] APIキー状態領域

- 概要: 選択中 AIサービスの APIキー保存状態を表示する領域。
- 表示内容: `APIキー状態`、`不要`、`保存済み`、`未保存` のいずれか、APIキーの補足説明を表示する。APIキーが必要な AIサービスでは `設定` ボタンを表示する。
- 依存情報:
  - 表示条件: 選択中 AIサービスがある。
  - 有効条件: APIキーが必要な AIサービスでは `設定` ボタンを操作できる。
  - 無効条件: APIキーが不要な AIサービスでは `設定` ボタンを表示しない。
- 操作: `設定` ボタンを押す。
- 結果: APIキー入力領域を表示する。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [8] APIキー入力領域

- 概要: APIキーを入力して保存または入力を取り消す領域。
- 表示内容: `APIキー`、パスワード入力欄、`保存` ボタン、`キャンセル` ボタンを表示する。
- 依存情報:
  - 表示条件: 選択中 AIサービスで APIキーが必要であり、APIキー入力領域が開いている。
  - 有効条件: `保存` ボタンと `キャンセル` ボタンは常に操作できる。
  - 無効条件: APIキーが不要な AIサービスでは表示しない。
- 操作: APIキーを入力する。`保存` ボタンまたは `キャンセル` ボタンを押す。
- 結果: `保存` ボタンでは APIキーを保存し、入力欄の値を画面から消す。`キャンセル` ボタンでは入力欄の値を消し、APIキー入力領域を閉じる。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [9] APIキー保存操作

- 概要: APIキー入力領域内の保存操作と取消操作。
- 表示内容: `保存`、`キャンセル` を表示する。
- 依存情報:
  - 表示条件: APIキー入力領域を表示している。
  - 有効条件: 常に操作できる。
  - 無効条件: なし。
- 操作: `保存` または `キャンセル` を押す。
- 結果: `保存` では選択中 AIサービスの設定を保存する。`キャンセル` では入力途中の APIキーを破棄する。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [10] 接続確認領域

- 概要: 選択中 AIサービスの接続確認状態を表示し、接続確認を実行する領域。
- 表示内容: `接続確認`、接続確認状態、接続確認の補足説明、`接続を確認` ボタンを表示する。
- 依存情報:
  - 表示条件: 選択中 AIサービスがある。
  - 有効条件: 接続確認中ではない。
  - 無効条件: 接続確認中は `接続を確認` ボタンを操作できない。
- 操作: `接続を確認` ボタンを押す。
- 結果: 選択中 AIサービスの現在の入力内容で接続確認を開始し、接続確認状態を更新する。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [11] 設定操作領域

- 概要: 選択中 AIサービスの設定を保存またはリセットする領域。
- 表示内容: `設定を保存` ボタン、`リセット` ボタンを表示する。
- 依存情報:
  - 表示条件: 選択中 AIサービスがある。
  - 有効条件: 保存中でなければ `設定を保存` ボタンを操作できる。リセット中でなければ `リセット` ボタンを操作できる。
  - 無効条件: 保存中は `設定を保存` ボタンを操作できない。リセット中は `リセット` ボタンを操作できない。
- 操作: `設定を保存` ボタンまたは `リセット` ボタンを押す。
- 結果: `設定を保存` では選択中 AIサービスの設定を保存する。`リセット` では選択中 AIサービスの設定を初期状態へ戻し、APIキー入力中の値を消す。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。
