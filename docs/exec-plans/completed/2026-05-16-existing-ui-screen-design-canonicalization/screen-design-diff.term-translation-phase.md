# 画面設計: 単語翻訳

```text
| +---------------------+ +--------------------+ |

| +---------------------+ +--------------------+ |
+------------------------------------------------+
```

## エレメント

### [1] 画面状態ヘッダー

- 概要: 単語翻訳段階の現在状態と、この画面で判断できる内容を示す領域。
- 表示内容: `translation-management`（翻訳管理内の画面であることを示す識別表示）、`単語翻訳`、`Gateway` の接続状態、段階状態、状態タイトル、状態説明、エラーメッセージを表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: なし。
  - 無効条件: なし。
- 操作: なし。
- 結果: なし。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。

### [2] 翻訳段階の操作領域

- 概要: 単語翻訳段階に対して行える操作を表示する領域。
- 表示内容: `翻訳段階の操作`、`操作`、現在の翻訳段階、`開始`、`中断`、`再開`、`リトライ`、`更新`、操作できない理由を表示する。
- 依存情報:
  - 表示条件: 常に表示する。
  - 有効条件: 各操作の実行可否が有効で、画面が読み込み中または送信中ではない。
  - 無効条件: 各操作の実行可否が無効、または画面が読み込み中、送信中である。操作できない理由がある場合は、操作名と理由を表示する。
- 操作: 操作ボタンを押す。
- 結果: 対象操作の送信後、単語翻訳段階の状態、進行状況、結果、失敗情報を更新する。
- セレクタ属性:
  - `data-testid`: なし。
  - `aria-label`: なし。
