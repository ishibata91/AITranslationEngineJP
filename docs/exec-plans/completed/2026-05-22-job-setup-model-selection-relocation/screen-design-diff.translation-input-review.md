# 画面設計差分: 翻訳入力レビュー

- `screen_id`: `translation-input-review`
- `status`: ready-for-human-review
- `source_plan`: `./plan.md`
- `canonical_target`: `docs/screen-design/screens/translation-input-review.md`

## 変更理由

翻訳入力レビューからジョブセットアップ画面へ進む導線を削除する。
選択済み入力データから翻訳ジョブを作成し、単語翻訳画面へ進む導線へ変更する。

## エレメント差分

### [1] 画面状態ヘッダー

- `変更種別`: 変更
- 変更後の表示内容: `翻訳管理`、`データロード`、`JSON を読み込み、登録結果と再構築の要否を同じ画面で確認する。`、接続状態、作業状態、作業状態の説明、ジョブ作成エラーを表示する。
- 変更理由: 翻訳ジョブ作成が入力データ確認後の操作になるため、作成失敗を同じ画面で確認できる必要がある。

### [7] 次の作業フッター

- `変更種別`: 変更
- 変更後の概要: 選択済みの読み込み済みデータから翻訳ジョブを作成し、単語翻訳画面へ進む固定フッター。
- 変更後の表示内容: `次の作業`、`選択した入力データで翻訳ジョブを作成し、単語翻訳へ進みます。`、作成できない理由、`単語翻訳へ進む` を表示する。
- 変更後の依存情報:
  - 表示条件: 選択データの状態が `登録済み` または `警告あり` の場合に表示する。
  - 有効条件: 選択データで翻訳ジョブを作成できる場合に操作できる。
  - 無効条件: 選択データが未選択、`登録失敗`、`再構築が必要`、またはジョブ作成条件を満たさない場合は操作できない。
- 変更後の操作: `単語翻訳へ進む` を押す。
- 変更後の結果: 選択した入力データで翻訳ジョブを作成し、作成されたジョブを選択状態にして単語翻訳画面へ進む。
- 変更後のセレクタ属性:
  - `data-testid`: `translation-input-review-next-action-footer`
  - `aria-label`: `次の作業: 選択した入力データで翻訳ジョブを作成し、単語翻訳へ進みます。`

## 削除する文言

- `翻訳設定へ進む`
- `ジョブの作成確認へ進みます。`

## 追加する状態

- ジョブ作成中。
- ジョブ作成失敗。
- 既存翻訳ジョブがある入力データを選んだ場合の再開案内。

## レビュー観点

- 次の作業フッターが翻訳設定ではなく単語翻訳を指している。
- 作成できない理由がフッター内で確認できる。
- AI モデル未選択を理由にジョブ作成が止まらない。
