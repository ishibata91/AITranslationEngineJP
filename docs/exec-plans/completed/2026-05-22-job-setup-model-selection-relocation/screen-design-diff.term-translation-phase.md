# 画面設計差分: 単語翻訳

- `screen_id`: `term-translation-phase`
- `status`: ready-for-human-review
- `source_plan`: `./plan.md`
- `canonical_target`: `docs/screen-design/screens/term-translation-phase.md`

## 変更理由

単語翻訳で使う AI モデル選択を、単語翻訳画面へ移す。
利用者は単語翻訳を開始する直前に AI サービス、モデル、実行方式を確認する。
単語翻訳画面の常時表示要素を、開始判断、進行状況、結果判断に必要な内容へ絞る。
主要要素は、デスクトップ幅では 2x2 程度の横並びにする。

## ワイヤーフレーム差分

```text
+------------------------------------------------+
| [1]                                            |
| +---------------------+ +--------------------+ |
| | [2]                 | | [3]                | |
| +---------------------+ +--------------------+ |
| +---------------------+ +--------------------+ |
| | [4]                 | | [5]                | |
| +---------------------+ +--------------------+ |
+------------------------------------------------+
```

追加: [2] AI モデル選択領域。
変更: 既存の進行状況、実行設定、結果、失敗情報は、段階状況領域と結果領域へ整理する。
配置: デスクトップ幅では [2] と [3]、[4] と [5] を 2 列に並べる。狭い幅では 1 列に折り返す。

## エレメント差分

### [2] AI モデル選択領域

- `変更種別`: 追加
- 概要: 単語翻訳に使う AI サービス、モデル、実行方式、一括処理、認証状態を選ぶ領域。
- 表示内容: `単語翻訳の AI モデル`、AI サービス、認証状態、モデル、モデル一覧更新、モデル一覧状態、処理方式、一括処理の切り替え、設定保存状態、開始できない理由を表示する。
- 依存情報:
  - 表示条件: 単語翻訳画面が表示されている。
  - 有効条件: 単語翻訳が未開始、または再試行前の設定更新が許可される状態の場合に操作できる。
  - 無効条件: 単語翻訳が実行中、または翻訳ジョブが終端状態の場合は操作できない。認証不足がある場合は開始できない。
- 操作: AI サービスを選択する。モデル一覧を更新する。モデルを選択する。処理方式を選択する。一括処理を切り替える。
- 結果: 単語翻訳用の AI 設定が更新され、単語翻訳の開始可否が更新される。
- セレクタ属性:
  - `data-testid`: `term-translation-phase-ai-model-selection-region`
  - `aria-label`: `単語翻訳の AI モデル選択`

### [3] 翻訳段階の操作領域

- `変更種別`: 変更
- 変更後の無効条件: 単語翻訳用の AI 設定が未完了、または認証不足の場合、`開始` は操作できない。
- 変更後の結果: `開始` を押すと、単語翻訳用の AI 設定を固定して単語翻訳フェーズを開始する。

### [4] 段階状況領域

- `変更種別`: 変更
- 変更後の概要: 単語翻訳の進行状況と固定済み AI 設定をまとめて表示する領域。
- 変更後の表示内容: 進捗率、処理済み件数、総件数、現在の処理段階、AI サービス、モデル、実行方式、一括処理を表示する。
- 削除する常時表示: 辞書 snapshot、開始時刻、完了時刻、共通辞書 hit 件数、AI 実行対象語件数の重複表示。

### [5] 結果領域

- `変更種別`: 変更
- 変更後の概要: 単語翻訳の成果、次段階へ進めるか、失敗時の短い理由をまとめて表示する領域。
- 変更後の表示内容: 確定訳語件数、ジョブ内辞書反映件数、次の翻訳段階、次の翻訳段階へ進めない理由、失敗時の短い理由を表示する。
- 削除する常時表示: 置換対象件数、未一致件数、`error kind`、`retryable` の常時表示。

## レビュー観点

- 単語翻訳画面内で AI モデルを選べる。
- `開始` の近くで AI 設定不足の理由を確認できる。
- 実行中は AI モデル選択が編集できない。
- 常時表示要素が、開始判断、進行状況、結果判断に絞られている。
- デスクトップ幅では主要要素が 2x2 程度で横並びになる。
