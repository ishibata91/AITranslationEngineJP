# 人間観測記録

## 観測対象

- 画面: マスターペルソナ画面
- 部位: AI 設定カード
- 操作: モデル一覧を更新する

## 観測事実

- モデル一覧を更新しても、モデルが選択できない。
- AI サービスのプルダウンがリセットされる。
- AI サービスの選択状態が、操作後に維持されない。

## 期待との差分

- 期待: モデル一覧更新後も、選択中の AI サービスが維持される。
- 期待: モデル一覧更新後に、取得済みモデルを選択できる。
- 差分: provider 選択状態のリセットにより、model 選択へ進めない。

## 既存根拠

- `2026-05-07-fake-fixed-model-closed-path` は、マスターペルソナで `fake-model` を選べることを人間確認に残していた。
- 実装結果は backend / integration 経路の検証通過を記録している。
- 実画面確認は未実施であり、モデルカードの表示と操作は人間確認で扱う残留リスクだった。

## 禁止事項

- 人間観測記録では原因を確定しない。
- 人間観測記録では修正ファイルを確定しない。
- `fake` provider ID を UI 表示候補へ追加しない。
