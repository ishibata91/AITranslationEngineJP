# 不足テスト

## 概要

- 対象: E2E-UC-048、E2E-UC-049（翻訳実行シェル「次のフェーズへ進む」）
- 判断: 追加候補あり（境界観点 1 件）
- 根拠: 既存 CSV の E2E-UC-048 と E2E-UC-049 は遷移後の表示確認を期待値に含む。しかし「遷移先 phase が元の phase に戻らない」という `$effect` 循環バグ由来の退行を明示的に防ぐ境界観点が CSV に記載されていない。今回の `untrack()` 修正で解消されるバグの再発を証明する観点として追加が必要。
