# 追加指示マトリクス案

## 目的

翻訳 prompt へ追加する指示を、ペルソナ、性別、年齢、種族の組み合わせから一意に作る。

各属性が同じ表現を奪い合わないように、担当を次へ分ける。

| 属性 | 主に決める対象 | 決めない対象 |
| --- | --- | --- |
| ペルソナ | 相手との距離、言葉の強さ、感情の出し方、文の勢い | 性別、年齢、種族固有の自称 |
| 性別 | 日本語で自然に選べる語尾、言葉の運び、一人称の候補 | 丁寧さ、乱暴さ、感情の強さ |
| 年齢 | 語彙の成熟度、文の長さ、落ち着き | 老人語や子供語の固定記号 |
| 種族 | 種族に一貫した発話慣習 | 一般的な性格や感情 |

## 組み合わせ数

| 軸 | 値 | 数 |
| --- | --- | ---: |
| ペルソナ | 9種類 | 9 |
| 性別 | 男性、女性 | 2 |
| 年齢 | 子供、成人、年配 | 3 |
| 種族 | 特別扱いなし、Khajiit | 2 |
| 合計 | `9 × 2 × 3 × 2` | 108 |

108通りは、次の3表から指示を1行ずつ選んで合成する。種族以外の組み合わせを54通り個別に保守する形にはしない。

## ペルソナの指示

| ペルソナ | 追加する指示 | 避ける表現 |
| --- | --- | --- |
| 冷然・見下し | 相手と距離を置き、冷たく短く言い切る。感情を抑え、相手を立てない | 原文にない罵倒、過度な敬語 |
| 淡々・実務 | 事実と用件を先に置き、感情を足さず簡潔に述べる | 親しげな終助詞、感嘆の追加 |
| 慇懃・端正 | 言葉を選び、整った常体で落ち着いて述べる | です・ます体への固定、過度な古語 |
| ぞんざい | 遠慮を置かず、短く直接的に言う。必要な場面では命令形を使う | 原文にない罵倒、「だぜ」などの反復 |
| 平明 | 飾らず率直に述べる。硬さ、乱暴さ、過剰な柔らかさのどれにも寄せない | 無個性にするための逐語訳、性別と年齢の消去 |
| 物腰やわ | 相手への配慮を言葉の選び方に出し、穏やかに言い切る | です・ます体への固定、女性語への固定 |
| 居丈高・罵倒 | 相手を圧する勢いで強く言い切る。原文に攻撃がある時だけ罵倒を訳へ出す | 原文にない侮辱の追加、同じ罵倒語の反復 |
| 率直・興奮 | 感情を隠さず、短い句と強い言い切りで勢いを出す | 情報の省略、感嘆符の過剰追加 |
| 情に厚い懇願 | 切実さと相手への信頼を出し、頼みを直接伝える | 過度な敬語、原文にない事情や感情の追加 |

## 性別と年齢の指示

ペルソナを性別や年齢で上書きしない。例えば、ぞんざいな年配女性は柔らかな女性語へ戻さず、ぞんざいさを保ったまま年齢と性別を言葉の運びへ出す。

| 年齢 | 男性 | 女性 |
| --- | --- | --- |
| 子供 | 子供が実際に使う短く平易な語彙にする。一人称が必要なら文脈に合う「僕」を使えるが、性別を示す語尾を無理に足さない | 子供が実際に使う短く平易な語彙にする。一人称が必要なら文脈に合う「私」を使えるが、性別を示す語尾を無理に足さない |
| 成人 | ペルソナに合う範囲で、簡潔な言い切りや硬めの接続を選べる。一人称が必要なら文脈に合う「俺」「僕」「私」から選ぶ | ペルソナに合う範囲で、柔らかな接続や省略形を選べる。一人称が必要なら文脈に合う「私」を使う |
| 年配 | 成熟した語彙と落ち着いた間で話す。ペルソナに合う範囲で簡潔な言い切りを使える。強いペルソナでも若者風の俗語を避ける | 成熟した語彙と落ち着いた間で話す。ペルソナに合う範囲で柔らかな接続を使える。強いペルソナでも若者風の俗語を避ける |

共通の禁止事項は次とする。

- 子供へ幼児語を固定しない。
- 年配者へ「わし」「じゃ」「のう」などの作り物めいた老人語を固定しない。
- 女性へ「だわ」「のよ」「ですわ」を固定しない。
- 男性へ「だぜ」「ぞ」「俺」を固定しない。
- 原文で主語を省ける場合は、性別を示すためだけに一人称を追加しない。

## 種族の指示

| 種族区分 | 追加する指示 | 理由 |
| --- | --- | --- |
| Khajiit | 原文で自分を指す必要がある時は、名前または「この者」などの三人称による自称を使う。主語を省ける文へ自称を毎回追加しない | 現行実装にも一貫した自称規則がある |
| Khajiit以外 | 種族だけを理由に語尾、硬さ、古風さ、性格を変えない | 共通して適用できる種族固有の発話規則を現在は固定できない |

現行実装は Argonian に「沼地の異邦人らしい硬さ」を追加している。この表では Argonian を「Khajiit以外」に含め、この指示を外す候補とする。

## 合成する指示の形

```text
- ペルソナ: {ペルソナ表の指示}
- 性別と年齢: {性別と年齢表の指示}
- 種族: {Khajiit の時だけ種族表の指示}
- 優先規則: ペルソナの強さを保ち、性別と年齢は語彙・接続・語尾の選択に重ねる。属性を示すために原文の意味を足さない。
- 禁止: 固定的な女性語、男性語、老人語、幼児語を反復しない。
- 例: {同じ組み合わせに対応する複数の英語原文と日本語訳文}
```

## few-shot の持ち方

- few-shot は属性ごとに別々の例を足すのではなく、4属性を合成した指示に対応する完成訳として持つ。
- 比較に使う例は同じ英語原文を使い、組み合わせだけを変えた日本語訳を対にする。
- 1つの組み合わせへ、平叙、疑問、依頼・命令を含む2〜4例を置く。
- 108通りすべてへ固有の例を持たせる前に、ペルソナ9種類と、性別×年齢6種類と、Khajiitの相互作用を覆う組み合わせで効果を測る。
- 実験では指示本文とfew-shot集合を一度に変えない。最初に合成した指示だけを測り、次の回で同じ指示へfew-shotを足す。

## 実験用の最小マトリクス

全108通りを最初からAPIへ送らず、次の組み合わせで相互作用を確認する。

| 段 | 組み合わせ | 確認できること |
| --- | --- | --- |
| 1 | ペルソナ9種類 × 成人女性 × 特別扱いなし | ペルソナの指示が女性表現に潰されないか |
| 2 | ペルソナ9種類 × 成人男性 × 特別扱いなし | ペルソナの指示が男性表現に潰されないか |
| 3 | ペルソナ9種類へ子供・年配を交互に割り当て、男女を均等にする | 年齢がペルソナと性別へ重なっても区別できるか |
| 4 | ペルソナ9種類 × Khajiit。年齢と性別を均等に割り当てる | Khajiitの自称規則がペルソナを消さないか |

段1と段2の18組は、各ペルソナで性別差を直接比較できる。段3と段4は、全組み合わせを列挙する前に年齢とKhajiitの相互作用を探る。効果が出た組み合わせだけ標本を増やし、確証では別の原文を使う。

## 組み合わせ別few-shotの予備の回

> 敵対的レビューで否決した。36例のうち、そのまま残せる例は6例、訳文を書き直せる例は11例、英語原文から差し替える例は19例だった。次のAPI送信には使わない。

現行の属性指示と現行の1例を残し、次の3原文に対する完成訳だけを追加する。

1. `I know this place well.`
2. `What are you doing here?`
3. `Come with me. We need to leave now.`

評価用の6原文はfew-shotへ使わない。12組で英語原文を共通にし、日本語訳だけを変える。

## 敵対的レビュー後の改訂案

### 72要求で測る組み合わせ

12組を手で抜き出す方式をやめ、次の4軸を完全に組み合わせる。

| 軸 | 今回測る値 | 数 |
| --- | --- | ---: |
| ペルソナ | 平明、ぞんざい、物腰やわ | 3 |
| 性別 | 男性、女性 | 2 |
| 年齢 | 子供、成人、年配 | 3 |
| 種族 | 特別扱いなし、Khajiit | 2 |
| 組み合わせ | `3 × 2 × 3 × 2` | 36 |
| 評価原文 | 2件 | 2 |
| API要求 | `36 × 2` | 72 |

平明は差が出にくいペルソナ、ぞんざいは現行でも差が出るペルソナ、物腰やわは性別との交絡が起きやすいペルソナとして選ぶ。3種類で成立した後に、残る6種類へ同じ形を広げる。

### 合成する評価原文

既存台詞へ依存せず、子供、成人、年配の誰が話しても設定と衝突しない内容にする。

| ID | 英語原文 | 主に観測する対象 |
| --- | --- | --- |
| E1 | `I was the one who heard the voice beyond the old bridge; no one else did. Come with me after the fog lifts, and we will find out who is there.` | 焦点を当てた一人称、語彙と構文の成熟度、同行要求の強さ。Khajiitでは三人称自称を必要にする |
| E2 | `The soup will burn if the fire stays this high. Move the pot to the stone ledge before it boils over.` | 条件と時間関係を保った命令、相手との距離、語彙と文の運び。自称がないため、Khajiitが不要な種族表現を足さない負の対照にする |

E1とE2は、few-shotに使わない。固有名詞、配偶者、職歴、戦闘経験、年齢を前提にする内容を入れない。

### 合成するfew-shot原文

3原文を36組で共通にし、日本語の完成訳だけを組み合わせごとに持つ。

| ID | 英語原文 | 役割 |
| --- | --- | --- |
| F1 | `I promised to return these books before sunset. Hold the door while I carry them inside.` | 約束と同時進行を保ちながら、自称、語彙、相手への指示を教える |
| F2 | `Did you hear footsteps upstairs? Stay beside the wall until the hall is quiet.` | 自称が不要な疑問と待機指示で、ペルソナを教え、Khajiit表現の過剰追加を抑える |
| F3 | `Leave the heavy box with him. Bring the sealed letter to me; I know where it must go.` | 対象人物との対比により自称を省けなくし、性別とKhajiit自称を教える |

API送信前にE1・E2とF1・F2・F3の全6対を機械検査と `fresh` の両方で確認する。次のいずれかに当たる対が1件でもあれば原文を再作成する。

- 小文字化して句読点を除いた後に、連続する4 token以上が一致する。
- 名詞だけを置き換え、節順、接続表現、代名詞の位置、発話の働きを維持したままfew-shot訳を評価原文へ移せる。
- 評価原文の主要な命令句または結びがfew-shotと一致する。

合格条件は、漏洩あり0/6対とする。

完成訳は次の規則をすべて満たす。

- 英語原文の命令、依頼、必要、否定、対比を別の発話の働きへ変えない。
- 原文にない感嘆符、疑問符、罵倒、懇願、事情を足さない。
- 複数文は句点ではなく全角空白で区切り、訳文末へ句点を置かない。
- 性別と年齢は、一人称1語だけで示したことにしない。3例の語彙、接続、命令または依頼の形を合わせて差を作る。
- 子供へ幼児語、年配へ固定的な老人語、女性へ固定的な女性語、男性へ固定的な男性語を要求しない。
- KhajiitはF1とF3で必要な三人称自称を使い、F2では種族だけを理由に自称を追加しない。
- 36組のうち、属性が異なる組で3訳すべてが同じになる組を残さない。
- 各完成訳は、API送信前に意味保持、書式、3例の束としての判別可能性をCodexの `fresh` が確認する。

### 判定単位

1文から4属性をすべて絶対判定する方式を廃止する。同じ条件のE1とE2を2訳の束にし、条件名と`custom_id`を伏せて次の比較単位で判定する。

| 属性 | 比較する訳文 | 判定 |
| --- | --- | --- |
| ペルソナ | 性別、年齢、種族を固定した3ペルソナの2訳束。12比較単位 | 平明、ぞんざい、物腰やわの対応をすべて選ぶ。区別不能を許す |
| 性別 | ペルソナ、年齢、種族を固定した男女の2訳束。18比較単位 | 男性、女性の対応を両方選ぶ。区別不能を許す |
| 年齢 | ペルソナ、性別、種族を固定した子供、成人、年配の2訳束。12比較単位 | 3年齢の対応をすべて選ぶ。区別不能を許す |
| 種族 | ペルソナ、性別、年齢を固定した2種族の2訳束。18比較単位 | E1でKhajiitの自称を正しく対応付け、E2の両訳に不要な種族表現がない場合だけ正解とする |

各比較単位の提示順を独立に乱す。判定者には英語原文、匿名化した2訳束、回答候補だけを渡す。条件ID、生成順、few-shot、answer key、別の比較単位を渡さない。各比較単位は新しい `fresh` の文脈で判定し、前の比較から属性の推測を持ち込ませない。`区別不能`は有効な回答だが正解数には入れず、対応をすべて正しく選んだ比較単位だけを1件の属性正解とする。

72訳を個別に次の4項目で判定する。

| 項目 | 合格条件 |
| --- | --- |
| `meaning_pass` | 行為者、対象、肯定と否定、条件と時間関係、情報量、発話の働きを保つ |
| `format_pass` | 全角空白による文区切り、文末、未翻訳、JSON断片、途中切れの規則を守る |
| `naturalness_pass` | 属性を示すための不要な情報追加や不自然な直訳がない |
| `non_caricature_pass` | 一人称1語または固定語尾の反復だけで性別と年齢を示さず、幼児語、固定的な老人語、女性語、男性語に依存しない |

比較単位は、属性の対応が完全に正しく、単位内の全訳が4項目すべてに合格した場合だけ正解とする。不合格訳を除外して分母を減らさず、不合格訳を含む比較単位は不正解として数える。`broken`は未翻訳、途中切れ、JSON断片、必須書式違反だけに限定し、意味の欠落を重ねて数えない。
