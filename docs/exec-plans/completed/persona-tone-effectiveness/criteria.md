# Criteria: persona-tone-effectiveness

## 完全な組み合わせによるfew-shot v2

敵対的レビュー後の予備の回では、平明、ぞんざい、物腰やわ×性別2×年齢3×種族2の36条件を完全に組み合わせ、合成した評価原文E1とE2の2訳束を比較した。各条件には別の合成原文F1、F2、F3の完成訳をfew-shotとして与えた。

条件名、生成順、few-shot、answer keyは評価者へ渡していない。72訳の品質は1つの `fresh` が条件を伏せて判定した。属性は60比較単位をそれぞれ別の `fresh` が判定した。

v3は因果的な改善量を測る回ではなく、採用可能な絶対品質を満たすかの受入確認とする。E1とE2の曖昧さを除くため評価原文を変えるので、v2との差をfew-shotだけの効果とは呼ばない。

### 組み合わせ

| 内訳 | 固定内容 |
| --- | --- |
| ペルソナ | 9種類をすべて含む。平明、ぞんざい、物腰やわは年齢または性別を変えて2件ずつ置く |
| 性別 | 男性6件、女性6件 |
| 年齢 | 子供4件、成人4件、年配4件 |
| 種族 | Khajiit 4件、特別扱いなし8件。Argonianは特別扱いなしの候補とし、この予備比較には入れない |
| 原文 | 疑問2件、依頼・命令1件、一人称を含む平叙3件 |
| 1回の翻訳 | 12組み合わせ×6原文の72要求 |

現行方式は同じ72入力で2度測る。属性名だけの予備の回は、説明文、年齢・性別ごとの言い回し、例文、Khajiitの自称規則を外し、`ペルソナ名・性別・年齢・種族名`の4行だけを渡す。統合指示の予備の回は現行の1例を残して説明文を合成した。組み合わせ別few-shotの予備の回は現行指示と現行1例を残し、12組ごとに平叙、疑問、同行要求の3例を追加した。base翻訳指示、モデル、原文、組み合わせ、判定規則は変えない。

### 判定値

`persona_fit`、`sex_fit`、`age_fit`、`race_fit` は `clear`、`weak`、`wrong` の3値とする。種族が特別扱いなしの場合と、Khajiitでも原文に自称を自然に出せる箇所がない場合は `race_fit` を `not_applicable` とする。`clear` は訳文だけから対象属性を積極的に読み取れる状態、`weak` は矛盾しないが属性が現れていない状態、`wrong` は別の属性に聞こえる状態とする。

- 予備の回では few-shot の集合だけを変える。base 指示、口調 directive、性質文、性別ラベル、モデル、標本、判定 prompt は変えない。

- 誤りの種類と重さは表の値だけを受け付ける。集計時の誤りの種類は、口調以外の破損、意味の変化、戯画化、A/B と answer key による性別の逆転または性別差なし、なしの優先順で確定する。A/B を伏せられた `fresh` が性別の逆転を推測した自由記入値は、answer key と矛盾する可能性があるため判定へ直結させない。

## 誤りの種類

| 種類 | 何を数えるか |
| --- | --- |
| 性別差なし | 男性条件と女性条件が同文、または違いがあってもどちらの性別に合うか判別できない |
| 性別の逆転 | 女性条件が男性に合い、男性条件が女性に合うと判定される |
| 意味の変化 | 行為者、対象、肯定と否定、発話の働き、または原文の情報量が変わる |
| 戯画化 | 性別を示す固定的な語尾や語彙を不自然に反復し、人物像より性別記号が前へ出る |
| 口調以外の破損 | JSON断片、未翻訳の英語、途中切れなど、口調と別に訳文として使えない |

重さは、大きいを意味の取り違えまたは訳文として使えない状態、小さいを意味は通るが不自然な状態とする。
