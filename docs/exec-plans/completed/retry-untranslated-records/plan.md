# Task Plan: retry-untranslated-records

`plan.md` は branch 情報と、人間が見た事象、そこから起こした要求を持つ。
設計は `design.md`、確定仕様は `spec.md`、恒久的に残す判断は `docs/changelog.md` が持つ。

## 事象

- 実行時タグの欠落または翻訳時のエラーで翻訳を飛ばした場合、利用者は未訳のまま残った件数を把握できなかった。
- 未訳を翻訳するために同じ plugin を再実行すると、既訳の収集、抽出、横断辞書の派生、取込などが再び動き、完了まで長く待つ。

## 要求

- **R-1 未訳件数を表示する**: 同期翻訳の完了時に、対象 plugin に未訳のまま残った件数を画面の完了案内へ表示する。
- **R-2 未訳だけを再実行する**: 登録済み plugin の再実行では、既訳の収集、抽出、横断辞書の派生、取込、口調の集計の完了が中心 DB に保存されている場合、各処理を繰り返さず、中心 DB に残る未訳だけを翻訳し、訳のある本文を変更せず、翻訳進捗の総数に未訳件数を出す。

## やらないこと

- 翻訳時のエラーや実行時タグの欠落を、未訳のまま残す現在の扱いは変更しない。
- plugin の内容を読み直して最初から翻訳する操作は変更しない。利用者は対象 plugin の成果を削除してから実行する。
- batch 翻訳の送信、状態確認、取り込みの流れは変更しない。
- 翻訳結果、横断辞書、plugin 内訳語、口調の決め方は変更しない。
