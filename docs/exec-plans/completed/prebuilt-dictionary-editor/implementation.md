# Implementation: prebuilt-dictionary-editor

## 変更した構成

- 用語辞書の作成、検索、更新、削除を、翻訳の読み取り経路と別に開く編集APIへ接続した。
- テーブルUIは原語、訳語、品詞の変更と削除の保留を別に保持する。
- テーブルUIは一つの編集する行だけを入力欄にし、行の切替、削除、取消、全て取消、作成、読み直しで入力欄を正しく切り替える。
- 用語辞書のカテゴリ検索は50件ごとの検索と、SQLiteの検索文字のエスケープを扱う。

## 仕様との対応

- R-1: 作成、更新、削除、表示後に内容が変わった場合の保存拒否、品詞の制約を用語辞書へ実装した。
- R-2: 4列フィルタ、Skyrimカテゴリ、総件数、50件のページを実装した。
- R-3: 編集APIと読み取り経路を別に開く構成を維持した。
- R-4: 変更した項目だけの更新、削除保留、保留中のページングと検索の無効化、全て取消を実装した。
- R-5: 行の取消で別の行の保留を残す処理を実装した。
- R-6: 一行だけの入力欄、行の切替後の保留維持、新規作成直後の入力欄、削除保留行の入力欄解除を実装した。
