# Task Plan: prebuilt-dictionary-editor

## 要求

- **R-1 用語辞書を編集する**: 用語辞書をテーブルUIから作成、閲覧、更新、削除できるようにする。
- **R-2 テーブルUIで絞り込む**: テーブルUIを50件単位でページングし、原語、訳語、品詞、Skyrimカテゴリでフィルタできるようにする。
- **R-3 編集APIを読み取り経路から分離する**: 編集APIを既存の読み取り経路とは別経路に重複して作り、既存の読み取り経路を変更しないようにする。
- **R-4 行ごとの変更を確定する**: テーブルUIの行の原語、訳語、品詞を列ごとに編集または削除保留にし、取消または確定までページングと検索を無効化する。確定では変更した項目だけを更新し、削除保留の行だけを削除する。Skyrimカテゴリは表示とフィルタの対象にする。
- **R-5 行ごとの保留を取り消す**: テーブルUIの各行で、保留した編集または削除を同じ取消操作によってほかの行の保留を残したまま取り消せるようにする。
- **R-6 編集する行だけを入力欄にする**: 用語辞書は通常時に文字表示し、編集を選んだ行だけを入力欄にしてGPU負荷を抑える。
