# Task Plan: batch-retry-untranslated-records

`plan.md` は branch 情報と、対象 task でやること・やらないことの要点を持つ。
設計は `design.md`、確定仕様は `spec.md`、恒久的に残す判断は `docs/changelog.md` が持つ。

## 要求

- **R-1 batch の完了画面で未訳と再送信を示す**: OpenAI と xAI の batch の取り込み後に、対象 plugin に残る未訳件数を表示し、未訳が残る場合は未訳だけを再送信することを画面に示し、未訳件数を取得できない場合はエラーを表示する。
- **R-2 batch の再送信では未訳だけを処理する**: 登録済み plugin の batch の再送信では、翻訳に必要な準備の完了が中心 DB に保存されている場合、既訳の収集、抽出、横断辞書の派生、取込、口調の集計を繰り返さず、中心 DB に残る未訳の固有名、叙述文、台詞だけを処理し、横断辞書または既訳を適用できない未訳だけを OpenAI または xAI の batch へ送り、各 batch へ送った件数を画面に表示し、訳のある本文を変更しない。
- **R-3 結果一覧を未訳だけに絞る**: 結果一覧に「未訳のみ」のチェックボックスを追加し、選択した場合は対象 plugin の結果全体を未訳だけに絞って未訳件数とともに先頭ページから表示し、取得に失敗した場合は選択前の表示を保ってエラーを表示し、訳のある本文があれば xTranslator への書き出しを選べる状態を保つ。

## やらないこと

- 通常実行の未訳件数表示と未訳だけの再実行は変更しない。
- batch provider の外部 API、状態確認の周期、結果の適用規則は変更しない。
- 翻訳時のエラーや実行時タグの欠落を未訳のまま残す扱いは変更しない。
- 対象 plugin の成果を削除して最初から翻訳する操作は変更しない。
- 「未訳のみ」の選択は xTranslator へ書き出す対象を変更しない。
