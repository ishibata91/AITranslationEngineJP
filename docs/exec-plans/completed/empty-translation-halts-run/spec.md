ii# Spec: empty-translation-halts-run

`spec.md` はこの task の確定仕様として、要求ごとの仕様を持つ。要求は `plan.md`、設計理由・変更手順・図は `design.md` が持つ。
`design.md` と `spec.md` が食い違う場合は `spec.md` を優先する。
各仕様の文は、実装へ渡す fail-test の観点と同じ文にする。

---

## R-1 固有名 1 件の skippable な失敗で実行を止めず、残り全件を訳し切る

- R-1-1（正常系）: 固有名 1 件の翻訳が構造化出力の空で終わったとき、その固有名を未訳のまま残し、残りの固有名と叙述文と台詞を訳し切ること。
    - 前提条件: 未訳の固有名が複数あり、そのうち 1 件の翻訳が構造化出力の空で終わり、他の固有名と本文は訳し切れる。
    - 確かめ方: 画面が失敗を出さずに実行を終え、訳された叙述文と台詞が画面に並ぶ。構造化出力が空で終わった固有名だけが未訳で残る。
    - 対応する実テスト: `internal/engine/proper_noun_test.go` の `TestRunSkipsProperNounOnStructuredParseFailure`。実画面でも確認した（`inigo.esp` で固有名 1 件だけ空応答を返すスタブを使い、実行が完了して台詞 8545 件が訳された）。
- R-1-2（対象に入る側の境界）: 固有名 1 件の翻訳が応答エンベロープの読み取り失敗またはサーバ一時失敗で終わったとき、その固有名を未訳のまま残し、残り全件を訳し切ること。
    - 前提条件: 未訳の固有名が複数あり、そのうち 1 件の翻訳だけが応答エンベロープの読み取り失敗、またはサーバ一時失敗で終わる。
    - 確かめ方: 画面が失敗を出さずに実行を終え、その固有名だけが未訳で残る。
    - 対応する実テスト: `internal/engine/proper_noun_test.go` の `TestRunSkipsProperNounOnSkippableProviderFailures`。
- R-1-3（対象に入らない側の境界）: 固有名 1 件の翻訳が skippable な失敗のいずれにも当たらない失敗で終わったとき、実行を止めて画面へ失敗を出すこと。
    - 前提条件: 固有名の翻訳が、構造化出力の空・スキーマ違反、応答エンベロープの読み取り失敗、サーバ一時失敗のいずれにも当たらない失敗で終わる。
    - 確かめ方: 画面に失敗が出て、叙述文と台詞が訳されないまま実行が終わる。
    - 対応する実テスト: `internal/engine/proper_noun_test.go` の `TestRunStopsOnFatalProperNounFailure`。

## R-2 実行完了時に、未訳のまま残した件数を画面へ出す

- R-2-1（正常系）: 実行が完了し未訳が複数残ったとき、未訳のまま残した件数を画面へ出すこと。
    - 前提条件: 実行が失敗せずに完了し、未訳が複数残った。
    - 確かめ方: 画面に残った件数が出て、その値が未訳の件数と一致する。あわせて、再実行でその件数を訳し直せることが画面に出る。
    - 対応する実テスト: `internal/store/target_plugin_test.go` の `TestCountUntranslated`（件数の値）。画面の文言は Storybook の story `Screens/翻訳実行 → 完了（未訳が残る）` と実画面で確認した（`17 件が未訳のまま残りました。もう一度実行すると、残った 17 件だけを翻訳します。`）。
- R-2-2（対象に入る側の境界）: 実行が完了し未訳が 1 件だけ残ったとき、その 1 件を件数として画面へ出すこと。
    - 前提条件: 実行が失敗せずに完了し、未訳が 1 件だけ残った。
    - 確かめ方: 画面に残った件数として 1 件が出る。
    - 対応する実テスト: `internal/store/target_plugin_test.go` の `TestCountUntranslated`（未訳 1 件のときの値）。画面表示は Storybook の story で確認した。
- R-2-3（対象に入らない側の境界）: 実行が完了し未訳が 0 件のとき、件数を画面へ出さないこと。
    - 前提条件: 実行が失敗せずに完了し、未訳が 0 件になった。
    - 確かめ方: 画面に件数が出ず、実行を終えた表示だけになる。
    - 対応する実テスト: `internal/store/target_plugin_test.go` の `TestCountUntranslated`（未訳 0 件のときの値）。画面で案内欄が出ないことは Storybook の story `Screens/翻訳実行 → 完了` で確認した。
- R-2-4（対象に入らない側の境界）: 実行が失敗で終わったとき、件数を画面へ出さないこと。
    - 前提条件: 固有名または本文の翻訳が、skippable な失敗のいずれにも当たらない失敗で終わり、実行が止まった。
    - 確かめ方: 画面に失敗が出て、件数が出ない。
    - 対応する実テスト: `internal/api/app_test.go` の `TestRunExtractAndTranslateOmitsCountOnFailure`。

---

前提条件に「なし」と書いた仕様が、状況によらず成立させる振る舞いになる。
「対応する実テスト」は `implementation-module` の最終検証で埋めた。
