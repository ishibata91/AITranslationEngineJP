# 人間観測記録

## 観測

- 画面: ジョブセットアップ画面
- 操作: モデルカードのモデル一覧取得ボタンを押す。
- 失敗: 必ず「モデルを取得できませんでした」と表示される。
- 比較: マスターペルソナのモデルカードではモデル一覧取得が成功する。

## 期待

- ジョブセットアップ画面のモデルカードも、保存済み provider 設定からモデル一覧を取得できる。
- マスターペルソナ画面と同じ provider 設定境界を使っても、Job Setup 固有の phase request token で失敗しない。

## 差分

- マスターペルソナは provider 設定の request token を provider 設定側へ渡す。
- ジョブセットアップは画面操作用の request token を provider 設定側へ渡している可能性がある。
