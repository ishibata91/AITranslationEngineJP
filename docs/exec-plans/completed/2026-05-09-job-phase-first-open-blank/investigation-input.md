## investigation_goal

- `jobID1` の初回「ジョブ段階へ進む」操作だけ、単語翻訳フェーズ UI が表示されない原因候補を観測事実として切り分ける。

## investigation_mode

- `修正前調査`

## known_context

- 人間観測では、初回起動時に `jobID1` で `ジョブ段階へ進む` を押すと、少なくとも単語翻訳フェーズ UI が表示されない。
- 添付画像では、`ジョブの進み方` は表示され、`単語翻訳` は `現在の作業` として強調される。
- 添付画像では、下部 panel が `ジョブ未選択` と表示し、`未完了ジョブ一覧でジョブを選んでください` と表示する。
- 人間観測では、一度一覧へ戻って同じ操作を再実行すると、単語翻訳フェーズ UI が表示される。
- 過去の修正履歴では、翻訳ジョブの初期 `ready` 状態と phase run 状態の不整合が修復済みである。
- 今回の症状は、初回遷移だけ単語翻訳フェーズ UI が表示されないことであり、過去の `ready` / `pending` 不整合と同一原因とはまだ判断しない。

## reproduction_steps

1. 開発環境を明示的に再起動する。
2. 翻訳ジョブ一覧を開く。
3. `jobID1` を対象にする。
4. 初回操作として `ジョブ段階へ進む` を押す。
5. 遷移後画面の表示状態、`ジョブ未選択` 表示の有無、単語翻訳フェーズ UI の有無、browser console、network、backend log を確認する。
6. 一覧へ戻る。
7. 同じ `jobID1` で `ジョブ段階へ進む` を再実行する。
8. 初回操作と再実行操作の差分を確認する。
