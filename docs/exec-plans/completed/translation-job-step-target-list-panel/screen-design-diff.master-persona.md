# 画面設計差分: `master-persona`

- `skill`: design-bundle
- `status`: approved
- `screen_id`: `master-persona`
- `source_screen_design`: `docs/screen-design/screens/master-persona.md`
- `source_plan`: `./plan.md`
- `source_storybook_review`: `./storybook-review-loop.md`

## 画面差分

### [1] 画面状態領域

- `変更種別`: 変更

概要:
画面名、現在フェーズ、状態、件数を共通の状態パネルで表示する領域にする。

表示内容:
- `マスターペルソナ`
- 現在フェーズ
- 状態要約
- 件数
- gateway 接続状態
- 通知メッセージ

### [2] 生成準備パネル

- `変更種別`: 変更

概要:
JSON 入力パネルを状態パネル直下に表示し、その下に進行状況と AI 設定を横並びで表示する領域にする。

表示内容:
- JSON 入力パネル
- 進行状況パネル
- AI 設定パネル

### [3] AI 設定カード

- `変更種別`: 変更

概要:
AI 設定カード自体をパネルとして表示する領域にする。

表示内容:
- AI サービス
- モデル
- 実行方法
- 資格情報の状態
- 資格情報の警告
- `モデル一覧を更新`
- `設定を保存`

### [4] 入力 JSON パネル

- `変更種別`: 変更

概要:
共通のファイル入力パネルで JSON ファイルの選択状態と生成対象件数を表示する領域にする。

配置:
状態パネルの直下に配置する。

表示内容:
- `入力 JSON`
- `JSON を選択`
- 選択中ファイル名
- 候補数
- 新規作成数
- 既存スキップ数
- `選び直す`
- `ペルソナを作成`

依存部品:
- `FileImportPanel`: ファイル選択、選択ファイル名、補助情報を表示する。

### [5] 進行状況パネル

- `変更種別`: 変更

概要:
JSON 入力パネルの下で、AI 設定パネルと横並びに進行状況を表示する領域にする。

表示内容:
- `進行状況`
- 進行メッセージ
- 状態値
- 進捗バー
- 処理済み件数
- 作成済み件数
- 現在の対象
- `一時停止`
- `中止`

### [6] 生成結果一覧パネル

- `変更種別`: 変更

概要:
マスターペルソナを処理対象一覧として検索、絞り込み、確認、操作する領域にする。

表示内容:
- `ペルソナ一覧`
- 検索欄
- プラグイン絞り込み
- 件数
- ページ操作
- 処理対象一覧
- metadata: `FormID`、`EditorID`、`対象プラグイン`、`元プラグイン`、`声`、`話し方`、`ペルソナ本文`、`最終更新`
- 行操作: 編集、削除

操作:
- 検索語を入力する。
- プラグインを選択する。
- ペルソナ行を開く。
- 編集を開始する。
- 削除を開始する。
- ページを切り替える。

結果:
- 条件に一致するペルソナ一覧を表示する。
- 開いたペルソナ行に metadata、ペルソナ本文、編集、削除を表示する。
- モーダルを表示する。

依存部品:
- `ProcessingTargetListWrapper`: 検索、絞り込み、件数、ページ操作、処理対象一覧をまとめて表示する。
- `ProcessingTargetListPanel`: ペルソナ一覧を処理対象一覧として表示する。

## 根拠

- `docs/screen-design/screens/master-persona.md` は、画面状態領域、生成準備パネル、進行状況パネル、生成結果一覧パネル、詳細パネル、モーダルを持つ。
- `storybook-review-loop.md` の `マスターペルソナ画面の一覧置き換え`、`マスターペルソナ詳細表示`、`マスター系画面のフェーズ構成化`、`マスターペルソナ JSON 入力の上段配置`、`マスターペルソナの進行状況と AI 設定` は、人間レビュー承認済みの画面仕様を示す。
- `storybook-review-loop.md` の `検索付き処理対象一覧ラッパー`、`処理対象一覧の詳細ブロック廃止`、`入力ファイル UI 共通化` は、人間レビュー承認済みの共通表示仕様を示す。
- `storybook-review-loop.md` の承認状態は `approved` である。
