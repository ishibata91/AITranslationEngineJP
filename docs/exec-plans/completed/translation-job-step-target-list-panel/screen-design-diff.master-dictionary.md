# 画面設計差分: `master-dictionary`

- `skill`: design-bundle

## 画面差分

### [1] マスター辞書画面

- `変更種別`: 変更

概要:
状態パネル、XML 入力、XML 取り込み進行状況、辞書一覧、モーダルを縦に表示する画面にする。

表示内容:
- 上部状態パネル
- XML 入力パネル
- XML 取り込み進行状況パネル
- 処理対象一覧として表示する辞書一覧
- 新規登録、更新、削除のモーダル

### [2] 上部状態パネル

- `変更種別`: 変更

概要:
画面名、現在フェーズ、状態、件数を共通の状態パネルで表示する領域にする。

表示内容:
- `マスター辞書`
- 現在のフェーズ: `マスター辞書管理`
- 状態要約
- 件数
- gateway 接続状態
- エラーメッセージ

### [3] XML 入力パネル

- `変更種別`: 変更

概要:
共通のファイル入力パネルで XML ファイルの選択状態を表示する領域にする。

表示内容:
- `XMLから取り込み`
- `ファイルを選択`
- 選択ファイル名
- 補助情報
- XML 待機説明

依存部品:
- `FileImportPanel`: ファイル選択、選択ファイル名、補助情報を表示する。

### [4] XML 取り込み進行状況パネル

- `変更種別`: 変更

概要:
選択済み XML の取り込み実行、進捗、結果を表示する領域にする。

表示内容:
- 選択ファイル名
- `この XML を取り込む`
- `選び直す`
- 取込状態値
- 進捗バー
- 取り込み結果

依存部品:
- `DictionaryImportProgressPanel`: XML 取り込み状態、進捗、実行、選び直し、完了結果を表示する。

### [6] 辞書一覧パネル

- `変更種別`: 変更

概要:
マスター辞書エントリを処理対象一覧として検索、絞り込み、確認、操作する領域にする。

表示内容:
- `辞書一覧`
- 検索欄
- カテゴリ絞り込み
- 操作ボタン
- 選択サマリ
- 件数
- ページ操作
- 処理対象一覧
- metadata: `辞書 ID`、`カテゴリ`、`登録元`、`最終更新`、`メモ`
- 行操作: 更新、削除

操作:
- 検索語を入力する。
- カテゴリを選択する。
- 新規登録を開始する。
- 辞書行を開く。
- 更新を開始する。
- 削除を開始する。
- ページを切り替える。

結果:
- 条件に一致する辞書一覧を表示する。
- 開いた辞書行に metadata と操作を表示する。
- モーダルを表示する。

依存部品:
- `ProcessingTargetListWrapper`: 検索、絞り込み、操作、選択サマリ、ページ操作、処理対象一覧をまとめて表示する。
- `ProcessingTargetListPanel`: 辞書一覧を処理対象一覧として表示する。
