# Design: prebuilt-npc-name-derivation

---

## R-1 事前作成辞書の NPC から人名の部分形の訳を本文の参考語へ加える

### 現況の理解

事前作成辞書の読取は、英語、日本語、`NPC_` を含む収録情報を読み取り専用で返す。`FULL` と `SHRT` は返さない。根拠は REF-1 と REF-2 である。

本文の参考語は、事前作成辞書と翻訳する plugin の翻訳済み固有名から作る。本文に含まれる英語だけを既存の最長一致規則で参考語として送る。根拠は REF-3 と REF-4 である。

人名の部分形を作る既存規則は、二つ名の前部、空白で区切る姓名、短縮名を別々に扱う。二つ名と姓名の規則は、用法の集計と、既にある英語を使って一般語との衝突を除く。根拠は REF-5 と REF-6 である。

同じ英語と日本語が複数の収録情報に現れる場合がある。NPC として扱う単位は英語だけでも日本語だけでもなく、英語と日本語の組である。根拠は REF-1 と REF-2 である。

| | 単位 |
| --- | --- |
| 要求が扱う対象 | 事前作成辞書の同じ英語と日本語の組に含まれる NPC の氏名 |
| 受け皿が持つキー | 本文の参考語の英語、日本語、品詞、`skyrim_category`、由来の組 |

### あるべき形

事前作成辞書の同じ英語と日本語の組に `NPC_` が一つでもある時だけ、人名の部分形を作る入力にする。

事前作成辞書は `FULL` と `SHRT` を区別しない。二つ名と姓名の規則だけに入力を渡す。短縮名の規則には入力を渡さない。

人名の部分形の訳は、既存規則が返した英語と日本語を持つ本文の参考語として、完全形と同じ翻訳の実行中に作る。事前作成辞書、横断辞書、翻訳する plugin の固有名へ保存しない。

既にある英語は、事前作成辞書の完全形と翻訳する plugin の翻訳済み固有名から集める。完全形または翻訳済み固有名が既に持つ英語には、人名の部分形の訳を加えない。

翻訳する plugin の短縮名が人名の部分形と同じ英語を持つ時は、短縮名を本文の参考語として使う。人名の部分形の訳は加えない。

用法の集計は、翻訳する plugin の会話文だけから作る。別の plugin の会話文は混ぜない。

同じ人名の部分形の英語と日本語は、既存の本文の参考語の重複判定へ渡す前に一つへまとめる。複数の `NPC_` がある時は、事前作成辞書の並び順が最初の `NPC_` の品詞と `skyrim_category` と由来を使う。本文に人名の部分形が含まれる時だけ参考語として送る。

同期翻訳と batch 翻訳は、共通の本文の参考語を作る入口を使うため、同じ人名の部分形の訳を送る。

### 変更後の責務

事前作成辞書の読取は、現在どおり読み取り専用で収録情報を返す。本文の参考語を作る処理は、NPC の氏名を二つ名と姓名の既存規則へ渡し、返った人名の部分形の訳を実行中の本文の参考語へ加える。人名の既存規則は採否だけを決める。
